# Product

## Register

product

## Users

协同系统运营和管理员，在现有后台页面维护平台、公共接入配置、仓库授权和店铺授权。

## Product Purpose

无需离开平台档案、接入配置、仓库档案即可维护极风库存 API 接入；店铺授权提供手动回填回调地址，作为自动回调失败时的补充入口。

## Brand Personality

清晰、谨慎、一致。沿用现有组件和样式，不做品牌改版。

## Anti-references

不增加装饰性页面；不把“保存成功”或“已绑定”显示成“实际连通”。

## Design Principles

- 公共配置与仓库凭据分别有唯一维护来源。
- 一次性授权与只读连接校验明确区分。
- 旧数据不覆盖，缺失项可定位。
- 凭据不回显，替换行为有明确提示。
- 手动回调保留店铺、配置、权限和一次性 state 校验，不修改平台登记的回调域名。

## Accessibility & Inclusion

沿用现有界面，新增字段保留可见标签、键盘操作和文字状态提示（用户已确认）。
