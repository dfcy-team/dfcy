## 实现内容

保留平台档案、接入配置、仓库档案。仓库表单与 API 接入弹窗写入同一仓库授权记录，Email、加密凭据引用和校验状态不存入普通仓库表。

公共配置只维护 API Base URL、Domain、Client ID、Client Secret。各仓库分别维护 OMS Email 和一次性 Token；首次授权生成的 OAuth access/refresh token 与 OMS Token 分开托管，OAuth userId 取自服务商响应。

保存与绑定均不代表连通。首次授权单独确认，禁用底层重试；一次性 Token 尝试标记先提交，失败或超时不自动重放。只读校验直接查询一页库存，不依赖已存在的同步任务，也不交换或刷新令牌。刷新授权需要明确点击，刷新后重新校验再启用任务。

旧记录保持不变，缺少仓库凭据显示待补充。编辑留空保留 Token。公共配置、凭据或绑定变化后使校验失效并停用关联任务。已绑定仓库变更平台、国家或类型前须先撤销绑定。

## 接口依据

用户提供的[极风 API 文档](https://s.apifox.cn/25bf1c44-f535-4c37-9bf4-7244130a67ce)：

- GET `/api/oauth/authorize`：domain、clientId、email、一次性 token，返回授权码。
- GET `/api/oauth/accessToken`：clientId、clientSecret、key，返回 OAuth 凭据及 userId。
- GET `/api/oauth/refreshToken`：clientId、refreshToken、userId（clientSecret 为文档可选字段）。
- POST `/api/inventory/queryInventory`：warehouse、pageNo、pageSize；校验只请求 pageSize=1。
- 返回 code=0 才认定成功；签名和库存字段沿用核对后的正式协议。
- 文档未定义 expireIn 数值单位，因此采用概述所述 24 小时有效期，不把该值猜作时间戳。有效凭据验收时仍需核对实际返回。
