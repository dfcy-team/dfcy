# 近7日已发货订单

数据源为已存在的 `sales_order_warehouse_lookup.snapshot.packages`，不新增三方请求、迁移或业务数据写入。只读取得当前租户及销售数据权限范围内的订单，沿用平台、国家、店铺和原币筛选；不按订单创建日期限制发货范围，避免漏掉旧订单近期发货。

计数单位为销售订单。存在有效带时区的实际 `shipped_at_utc`、且对应包裹未取消时，以同订单最早实际发货时间转换到店铺当地日期归集。分包订单只记首次发货一次，不代表所有包裹均已发完。无有效日期不计，未观察日期显示缺失而非零。当前查询当天时的“近7日趋势（截至昨日）”增加此字段；按自定义日期查询的原趋势不改统计口径。

源字段 `shipped_order_count` 不参与币种换算；CNY等合并展示仅累加已观测计数，保留缺失语义。源仓库记录随同步更新，大屏独立后台快照自然刷新，无前台同步请求。新增只读查询在2026-11-17正式库核验约0.31秒；采集仍在持续，数量会变化。

前端保留销售额折线（右轴），订单总量黄柱、已发货订单蓝柱共用左轴。悬停提示、十字线及每日数值表均包含已发货订单。正常后台更新不增加常规提示。

验证：backend/tests/test_board_shipping.py 覆盖当地日边界、重复订单、分包首次发货、取消/缺失/非法/无时区时间及币种合并；frontend/tests/board-chart-pointer.spec.js 覆盖新增柱形与缺失值及悬停行为。上线后以正式HTTP返回、独立源数据聚合、页面人工验收为最终依据。
