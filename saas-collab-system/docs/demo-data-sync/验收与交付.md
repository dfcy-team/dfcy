## 审查问题与修复

| 问题 | 修复和证据 |
| --- | --- |
| 环境撤销后 queued 状态无法释放 | 停用事务内终止 queued，测试验证恢复后可新建 |
| 撤销后仍可继续下一页读取 | 每页检查环境、发起人当前权限和任务租约；测试验证仅一次请求后停止 |
| 库存出口不含仓库来源平台 | 独立创建禁用 jifeng_wms 本地来源；真实合同投影、库存单独导入测试通过 |
| 整数赋给库存来源 FK | 改为来源对象绑定，原生模型校验通过 |
| 分类 ID 小于后来创建的父节点 | 拓扑排序导入，并拒绝分类环 |
| 跨源 ID 或新快照覆盖测试修改 | receipt 固定首次包；同包 no-op、不同包拒绝；测试保留本地状态修改 |
| 实际 API 不接受统一 scope 参数 | 主数据仅分页，订单逐店铺/日期、库存逐仓库/日期；公开合同集成测试通过 |

## 菜单、权限与部署差异

新增唯一业务菜单 `/system/demo-data-sync`，位于系统管理末尾；新增相应 route capability、菜单登记、四项操作权限及派生清单。既有菜单名称、路由与顺序未调整。

新增内部接口前缀 `/api/internal/demo-data-sync/`，仅管理内网同步服务自己的任务与包。新增两套专用 settings；原生产 Compose、业务只读 v1 路径、既有迁移及镜像均未改动。

默认关闭。生产 client 的创建、审批、启用、内网服务部署及数据首次拉取没有执行。已有合成沙箱入口和 synthetic seeder 不作绕过修改。

## 尚需验收

在新建内网 MySQL 服务及新 Demo 工作库执行迁移预检与非空导入；配置批准的源 client、证书、固定源域名与来源白名单；限定单店铺/仓库、小日期窗口做链路和报表验收，再确定并发、页大小和暂停阈值。

首期不包含可靠变更增量/删除传播、严格时点快照、无人值守调度、财务广告扩展、平台站点与完整商品分类映射。后台任务在专用 settings 禁用，部署不得启动既有业务 worker/beat。现有国家出口不等于 PlatformSiteMaster，相关报表仍需独立合同。

部署职责、配置模板、手动执行、dry-run/commit、新工作库刷新及回滚步骤见 README.md；代码清单和哈希见 change-manifest.json。
