# 国内承运商与国内运费付款

日期：2026-10-29。当前为本地开发候选，未部署。

## 操作流程

1. 在货运公司档案维护承运范围，可多选国内运输、国际运输、目的国配送，并维护该公司的对公/对私收款账户。既有档案默认国际运输；需要承担国内运输时勾选国内运输。
2. 保存供应商发货草稿后，在“国内运输 · 供应商至集货站”选择国内承运商、填写国内运单号并单独保存。供应商仅可修改自己草稿，采购可维护有权限的草稿或已提交发货单。
3. 在费用与结算的供应商发货单内，维护并确认原有国内发货费用。此费用仍按原分摊规则进入商品成本。
4. 展开“国内运费付款”，从对应货运公司收款账户中选择账户，填写本次金额、日期，保存后上传付款凭证。系统显示应付、累计已付、剩余未付，保留对公/对私账户快照。
5. 错误付款通过冲销更正，保留原记录与凭证。存在有效国内运费付款时更换承运商，须先冲销原付款。

## 业务边界

- 供应商货款、供应商至集货站的国内运费、集货批次运费分别记账。国内运费不抵扣采购定金，也不减少供应商货款欠款。
- 国内运费应付取发货单当前已确认费用；付款只登记资金记录，不再新增一次商品成本。
- 国内运费已有有效付款时，费用不能改为暂估或低于已付金额。更正前先冲销对应付款。
- 历史发货单不强制补承运商；登记新国内运费付款前必须选择。历史供应商货款期初不作为国内运费期初。
- 目的国配送仅为档案承运范围分类，本次未新增配送业务流程。
- 国际批次继续使用独立的批次货运公司字段。

## 性能与权限

承运商选项打开时才分页读取，搜索防抖；国内付款区展开时才加载。发货单列表预加载承运商关联，避免逐行查询。选项仅返回编号与名称，不向供应商公开银行账户。

付款与凭证按租户、单据权限和付款用途分别校验；收款账户必须属于所选国内承运商。重复请求使用幂等键，发货单修改校验版本。
