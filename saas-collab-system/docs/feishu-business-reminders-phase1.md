# 飞书部门业务提醒：第一期开发交付

开发基线：`7b5849cac46b94d46b1a25ccd38d17e7093f1bff`（origin/main，V2.44.266）。
分支：`codex/feishu-department-reminders-phase1-20261020`。

## 使用流程

1. 在组织架构编辑部门，选择负责人，并设置“仅本部门”或“包含下级部门”。负责人须为同租户启用的内部用户。配置变动写入现有操作日志。
2. 管理员或负责人打开销售订单、退款退货页面。勾选当前页记录后点击“提醒所选”，或通过右侧、滚动按钮上方的“飞书提醒”选择已查询筛选范围。
3. 面板中搜索可管理人员，填写标题、留言及可选截止日期，生成逐人预览。未绑定飞书或无共同业务权限的收件人不能发送，须移除后重新预览。
4. 确认后加入现有后台投递队列；发送记录显示逐人待发送、处理中、成功或失败状态，并可按既有三次上限重试。入队不代表送达。

消息包含共同可见记录数、人工留言和系统详情链接；不自动复制订单号、客户、金额或原始记录。负责人留言须自行避免敏感资料。截止日期在本期作为消息内容，逾期自动催办属于后续范围。

## 权限与范围

- 管理员限定为平台超级管理员或有效租户管理员，仍受租户和业务查看权限约束。
- 负责人按有效部门树限定收件人；主部门、兼任部门及有效组织成员关系均参与人员匹配。停用部门不参与遍历。
- 发送人和收件人的业务范围取交集；所选模式要求全部所选记录对双方可见，筛选模式可生成每位收件人不同的数量。
- 收件人权限来自部门岗位时，预览选择有效组织身份并保存到投递；执行时重新检查身份有效期。链接携带身份，进入系统时刷新该身份权限。
- 投递前复核发送人身份、部门关系、双方业务权限、收件人绑定及应用连接。卡片链接也在服务端重新施加原提醒范围。无默认日期、单边日期都不会被浏览器额外截为近30天。
- 从提醒链接再次发起时，只允许勾选具体记录，避免把原提醒范围扩大为普通日期范围。
- 预览签名有效期10分钟；内容、数量、身份或可投递状态改变后须重新预览。请求编号在同租户、同发送人下唯一，网络重试复用原编号，同编号不同内容被拒绝。

## 性能边界

- 所选最多100条，收件人最多50名；候选搜索300ms防抖，返回最多100名，不拉全量用户。部门负责人搜索沿用现有用户目录的可见范围。
- 筛选模式必须有起止日期，最多31天、10000条共同可见记录。计数通过带10001上限的子查询完成，不读取全部业务明细；超过上限要求缩小范围。
- 复用销售和退款页面的筛选函数，不执行整页序列化、汇率换算、商品行汇总或报表导出。发送人计数每次预览一次，收件人统计逐人计算；部门岗位上下文仅在默认授权不能满足时尝试，最多10个有效岗位身份。
- MySQL计数查询附加`MAX_EXECUTION_TIME(1000)`优化器提示；MariaDB及其他后端不使用该提示。预览在处理下一收件人或组织身份前检查6秒预算，超限要求减少收件人或缩小范围。此预算不是所有数据库下的强制整请求超时。
- 复用现有持久化投递队列、租约和防重复机制，页面不等待外部飞书发送。发送记录有租户/发送人索引，投递按提醒外键查询。
- 本地SQL结构检查覆盖单收件人的两次事实计数；没有阿里云真实数据规模的P95或执行计划验收结论。

## 接口与迁移

接口前缀：`/api/internal/integrations/feishu/business-reminders/`。

| 接口 | 用途 |
| --- | --- |
| `GET options/` | 发送资格、数据源及可管理人员搜索 |
| `POST preview/` | 验证来源及逐人预览，返回签名 |
| `POST send/` | 签名和请求编号校验，事务入队 |
| `GET /` | 最近30条本人记录；管理员可看租户记录 |
| `GET <id>/` | 逐人投递状态 |
| `POST <id>/` | 指定失败投递重试 |

新增迁移：`tenants/0002_department_leader_and_more`、`integrations/0049_feishubusinessreminder_and_more`。只增加部门负责人字段、提醒表及可空投递外键，不回填负责人、不改已有授权、不创建定时提醒规则。没有变更菜单、依赖、部署或Compose文件。

## 验证和上线边界

已验证：新增权限与投递用例、销售/退款筛选及查询效率回归、组件预览失效/超时重试/详情链接范围、前端构建、菜单及权限引用快照、迁移一致性和Django系统检查。部门配置4项和新提醒首轮14项用例经过完整迁移的内存测试库；其余定向回归使用`--nomigrations`加速。

浏览器使用本地合成数据，覆盖表格勾选、快捷入口、选人、预览、确认入队和状态展示；桌面1280像素及手机390像素截图在项目外审查目录保存。本地交互不会调用真实飞书或生产API。

本交付为开发候选。尚未推送、合并、构建受控镜像或部署；上线需要架构员执行正式迁移与发布，并以实际部门角色、飞书绑定账号完成送达及详情链接验收。真实连接权限、后台队列运行与生产数据性能须在该验收中核实。
