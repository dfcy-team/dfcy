## 验收约束
- 状态：待办理、办理中、待确认、已关闭；关闭原因独立保存。
- 主处理人唯一；协办人可多选；发起人不可篡改。
- 按租户、参与关系和事项归属部门授权访问；包含下级需明确配置。
- 调岗或改派不隐式改变归属部门；跨部门移交校验双方范围并留痕。
- 关联业务访问权限独立校验；关闭事项不改变业务状态。
- 服务端记录时间；改期、催办、退回、重开及关闭均可追溯。时间界面统一显示北京时间。
- 未关闭事项默认不按创建时间截断；历史逾期不会因完成而抹除。
- 截图主动触发，支持提交前预览、裁剪和标注，附件遵循事项访问权限。
- 首期仅站内通知；外部发布不在本地开发范围。
