# 驾驶舱销售与补货参考

供应链驾驶舱增加“销售与补货参考”页签。选择基础档案国家，设置历史销售日期、周期/季节、目标库销比和是否计入有效到货，再手动生成参考。默认只显示建议量大于零的商品，可切换待核对/全部/无需订货；筛选仅作用于本批最多 20 个候选，不是全目录查询结果。普通商品参与订货，虚拟和组合商品仍不参与；组合销量按已有公式折算至普通商品。

每行展示新旧 SKU、商品图片、国家销量及组合折算、日均需求、库存覆盖天数、可用库存、有效到货、开放需求和建议量。按平台分析继续使用既有授权平台及贡献口径，建议量按国家计算，不重复分摊共享库存。

“查看依据”展示已加载的仓库快照及阻断项，不增加逐行查询。覆盖天数只是历史日均需求下的可用库存覆盖参考；存在阻断问题或缺失依据时显示待核对，不作为预测。季节类型仍使用人工选取的历史区间，不新增季节预测模型。

勾选正数建议后，“带入运营订货草稿”只传递当前会话中的商品选择，不创建订单。交接绑定账号、租户和组织成员身份，一次性消费，15 分钟过期，不写 localStorage 或 URL。进入运营订货页重新调用预览，只有人工点击保存才创建草稿，提交采购仍是后续独立动作。刷新页面会丢失未保存选择。

账号/组织或授权状态切换同步清空驾驶舱缓存、待办、运营表单和预览，并令旧异步响应失效。入口要求运营订货查看、维护及菜单权限；实际销量/库存权限由现有服务端接口校验，不自动授予角色。

同时修复无采购单时国家列表为空导致三方仓库存不可见的问题。国家选项加入库存授权内的基础档案国家；排名前仅限制租户/来源/国家身份，失败、过期、商品映射和商品类型检查仍在取最新身份之后。减少历史排名中的配置联查，超过 2,000 个来源运行时使用完整子查询，不截断历史。

验证：后端 11 项针对性测试；前端 29 项测试；菜单/权限清单、Django check、生产构建、diff 检查通过。真实 Edge 隔离模拟验收包括国家选择、生成参考、依据弹窗、勾选、跳转和重新预览，并确认无订单保存请求。手机 390×844、桌面 1440×1000 已检查。新 UI 尚未部署到虚拟机或阿里云，正式页面真实权限及端到端速度需发布后验收。

此前阿里云只读诊断中，库存候选计算约 5.7 秒，原查询超过 8 秒上限；该值不是浏览器加载耗时，也不是新页面上线后的承诺。菲律宾 3 条最新库存未映射、其他候选销量覆盖不足等数据问题未自动修改。未导入虚拟机示例或生成正式业务单据。
