# 全国家补货后台清单

## 验收目标

采购驾驶舱和运营订货使用同一份按当前国家、当前账号权限生成的完整参考结果。点击生成只建立任务，不在HTTP请求中扫描销售或库存事实；任务按20个SKU分批执行。完成后，“建议新增量大于0”等筛选作用于完整结果，返回真实数量并分页，不再让操作人逐批查找候选。

所有结果仅供参考；选中商品进入运营订货时仍通过现有预览重新计算，保存/提交继续检查库存、采购、需求和策略依据，不能用过期后台结果直接创建业务单据。

## 执行与一致性

- 任务捕获候选SKU集合，排除虚拟和组合商品；不能以不断变化的商品列表offset作为计算检查点。
- Celery每批最多20个SKU，计算后事务写入行结果和进度，再排队下一批；重复消息、旧租约和取消竞态不能增加重复行或覆盖新进度。
- 页面轮询只读取任务元数据；完成后的搜索、数量/风险筛选与分页只查询结果表，不重新扫描事实表。
- 计算观察是分批完成的，不声称全国家销售和库存来自同一数据库事务快照。界面显示观察开始/结束时间，每个商品保留来源依据。
- 策略版本、账号权限、组织成员上下文或业务日期变化会使旧任务失效。完成结果15分钟到期，计算总期限2小时，队列故障明确提示，禁止退回HTTP内同步执行。
- 授权绑定租户、账号和组织成员，任务不可跨账号或跨成员上下文复用；每次轮询、读取及每批执行重新核验权限。
- 同配置活动任务合并，设置账号/租户活动任务上限；失效结果定期分批清理，清理行数也必须有上限。

## 页面

生成按钮明确触发任务；排队/运行显示已处理数、总候选数、进度及取消入口。完成后展示全局正数建议、待核对及风险汇总，搜索和切换筛选不重新计算。勾选跨结果分页保留，单次最多100个SKU；切换国家、参数、账号、成员上下文或新任务时清空勾选。卸载后停止轮询，旧响应不能回填当前页面。

## 测试关卡

1. 45个候选且仅后25个有正数建议，完整结果过滤必须返回25，而不是第一页零条。
2. 排队、进度和结果GET不调用销售/库存计算器；不得将API超时时间调长作为解决办法。
3. 重复执行同一任务消息、过期租约结果、取消后返回的计算结果均不得重复写入或标记完成。
4. 跨租户/账号/组织成员读取拒绝；撤权和策略更新后旧任务不能读取或继续计算。
5. 计算失败、队列不可用、结果到期有明确状态，不显示部分结果为完整清单。
6. 两个页面入口选中商品仍只生成预览，不自动保存或提交单据。
