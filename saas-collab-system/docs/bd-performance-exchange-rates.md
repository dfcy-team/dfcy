# BD 绩效汇率配置

## 范围

在“达人管理 / BD 配置”页新增独立的“BD 绩效汇率”区块。
原有默认指标视图、每日归因补偿、送样逾期时长、送样逾期提醒四项不变。
不恢复默认币种或默认归因方式配置，不修改销售、财务模块的汇率。
本增量只改变 BD 金额换算来源，不实现整单归属，不改订单、送样或负责人关联。

## 可配置内容

| 字段 | 含义 |
| --- | --- |
| 币种 | PHP、MYR、THB、USD；人民币 CNY 固定为 1 |
| 汇率 | 1 单位所选外币等于多少 CNY，十进制文本，必须大于 0 |
| 适用起始日期 | 汇率从哪个业务日期开始适用，含当天 |
| 备注 | 可选，最多 240 字，不可填写密钥或密码 |

同一币种可以配置多个日期。同币种、同日期禁止重复。
每个配置版本最多 1000 行，最多 10 位整数和 10 位小数，不接受浮点 JSON、科学计数法、零或负数。
日期范围为 1900-01-01 至 2100-12-31。

## 历史口径

报表一次计算固定读取当前租户最新的、已启用的完整汇率清单，不读取待审批版本。
订单金额用订单统计业务日期选择汇率；送样投入按现有送样业务日期选择汇率。
对于每个币种，取适用起始日期不晚于业务日期的最近一条。

例如配置 PHP：2026-08-01 起为 0.125，2026-09-01 起为 0.13：

- 8 月的 100 PHP 换算为 12.5 CNY。
- 9 月的 100 PHP 换算为 13 CNY。
- 若要改算 8 月，在新版本中修改或增加从 2026-08-01 起适用的记录。

新版本生效后，重新查询历史月份会按该版本清单计算。旧配置版本与变更日志保留，
但本功能不冻结历史报表结果；需要留存旧结果时，应保留带汇率版本信息的对账输出。

未配置的币种、配置起始日期之前的业务日期、未启用汇率版本或空清单，继续读取原有
达人模块 `ExchangeRate`。两种来源都缺失时仍报告汇率缺失，不使用外部市场报价或猜测金额。
已命中的配置异常时不得静默改用旧汇率。

## 计算边界

BD 本币金额仍使用 `estimated_commission_base`，不使用 `payment_amount`，不乘数量。
订单资格仍是“联盟已结算 + 明确未全额退款”，送样匹配与归因规则不在此增量修改。

换算为人民币：本币预估计佣金额 × 本币到人民币汇率。
换算为其他展示币种：金额 × 来源币到人民币汇率 ÷ 展示币到人民币汇率。
完整且可用时 ROI = 同币种预估计佣金额 /（送样成本 + 实际标准佣金 + 实际广告佣金）；金额、任一成本或必要汇率缺失时不将 ROI 猜成 0。

汇率变化只影响换算金额和 ROI，不影响本币金额、有效订单数、送样数量及负责人关联。
不需要重新导入订单或重生成订单归因快照，重新查询报表即可读取新的生效汇率。

## 修改、删除与数据存储

配置键：`influencers.bd.exchange_rates`，租户级 JSON，无需审批。
查看、保存、回滚复用 `config.view/manage/rollback` 权限及租户内 ALL 数据范围。
配置启用时间由服务端设为保存时刻；每行的业务适用起始日期仍可设置未来日期。

- 修改：直接修改表格单元格，点击“保存汇率”。
- 删除：点击行末“删除”并确认，再点击“保存汇率”；未保存时不影响报表。
- 删除最后一条并保存：提交空清单，恢复原有 BD 汇率来源，不物理删除历史记录。
- 每次保存均创建完整清单的新版本，并保留旧版本和变更日志；回滚也创建立即生效的新版本。

升级保留原有待审批版本，不自动批准或启用。页面可载入其内容，用户明确保存后才生成
免审批的新版本。已批准的旧延时版本继续沿用原定计划，但不能覆盖更新的生效版本。
其他配置的审批规则不在本次修改范围内。

```json
{
  "rates": [
    {
      "currency": "PHP",
      "rate": "0.125",
      "effective_from": "2026-08-01",
      "note": "示例值，请按实际业务确认"
    }
  ]
}
```

示例不自动作为默认汇率写入数据库。
使用 `TenantConfigVersion` 和 `ConfigChangeLog` 存储版本与变更记录；
不向 `ExchangeRate` 复制一套互相竞争的配置数据。
报表接口提供使用的配置版本、适用起始日、业务日期及原汇率来源以支持对账。

## 部署边界

后端升级执行 `0037_bd_exchange_rates_direct_save`，只将汇率定义改为免审批；前端需重新构建。
迁移不插入默认生效汇率，不修改已有配置版本、联盟订单、送样数据或原归因快照。
本地实现和隔离测试不等于已部署到 VM34 或 VM10。
