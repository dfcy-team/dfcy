# 达人订单与视频数据导入说明（VM10）

本文供 VM10 管理员执行达人模块真实数据导入。执行前必须确认租户 ID、备份数据库，并将源 CSV 放在 VM10 应用容器或后端进程可读取的位置。不要直接使用示例数据覆盖生产数据。

## 一、联盟订单

目标模型：`influencers.AffiliateOrderSnapshot`  
目标表：`influencers_affiliateordersnapshot`

必填字段及可识别中文表头：

| 标准字段 | 可识别表头 | 用途 |
| --- | --- | --- |
| `data_time` | 订单日期、订单时间、下单时间 | 订单业务时间 |
| `shop_abbr` | 店铺简称、店铺 | 匹配租户店铺 |
| `site` | 站点、国家、country、marketplace | 订单站点 |
| `order_id` | 订单 ID、订单号、订单编号 | 订单标识 |
| `product_id` | 商品 ID、商品编号 | 商品标识 |
| `sku_id` | SKU ID、商品 SKU、子商品 ID | SKU 标识 |
| `creator_username` | 达人账号、达人用户名、creator_handle | 匹配达人账号 |
| `payment_amount` | 支付金额、订单金额、gmv | GMV |
| `quantity` | 数量、商品数量 | 有效订单数量 |
| `currency` | 币种、货币 | `CNY/PHP/MYR/THB/USD` |
| `fully_returned` | 全额退款、是否全额退款 | 排除全退订单 |
| `order_status` | 订单状态、status | 判断有效订单 |

可选字段：`shop_name`、`product_name`、`product_price`、`actual_paid_commission`、`estimated_paid_commission`、`export_time`、`created_at`。

导入命令会直接写库，必须先在数据库备份或临时租户中验证：

```bash
python manage.py import_affiliate_orders_csv \
  --tenant-id <TENANT_ID> \
  --file /path/to/orders.csv \
  --source affiliate_export
```

同一租户和来源使用租约防止并发导入；相同订单行按来源键和内容哈希幂等更新。

## 二、视频结果

目标模型：`influencers.VideoResult`  
目标表：`influencers_videoresult`

CSV 表头要求：

| 字段 | 必填 | 用途 |
| --- | --- | --- |
| `video_id` | 是 | 视频唯一标识 |
| `data_time` | 是 | 指标日期 |
| `creator_id` | 是 | 优先匹配档案外部达人 ID |
| `creator_name` | 是 | ID 未匹配时按 TikTok 账号匹配 |
| `vv` | 否 | 播放量 |
| `orders` | 否 | 视频订单量 |
| `gmv_video` | 否 | 视频 GMV |
| `currency` | 建议 | GMV 币种；缺失时记录 `UNKNOWN` |
| `publish_time` | 否 | 发布时间 |
| `video_type` | 否 | `video`、`live` 或 `直播` |
| `video_title` | 否 | 视频标题 |
| `shop_abbr` | 否 | 匹配店铺 |
| `export_time` | 否 | 数据源更新时间 |

先执行只读预检，不带 `--apply`：

```bash
python manage.py import_video_results_csv \
  --tenant-id <TENANT_ID> \
  --file /path/to/videos.csv \
  --source video_export
```

重点检查输出中的 `unmatched`、`ambiguous` 和 `invalid`。确认后正式写入：

```bash
python manage.py import_video_results_csv \
  --tenant-id <TENANT_ID> \
  --file /path/to/videos.csv \
  --source video_export \
  --apply
```

## 三、导入后刷新

```bash
python manage.py refresh_bd_order_attributions --tenant-id <TENANT_ID>
python manage.py refresh_influencer_video_profiles --tenant-id <TENANT_ID>
python manage.py aggregate_influencer_cooperation --tenant-id <TENANT_ID>
```

刷新后检查：联盟订单数、视频结果数、无法匹配达人数量、达人平均播放、历史 GMV、订单数及 BD 绩效。`creator_username`、`creator_name` 或 `creator_id` 无法对应达人档案时，数据不会归属到该达人。

## 四、管理员回执

管理员应记录以下信息：

- 租户 ID、源文件名及文件哈希。
- 导入前后目标表行数。
- 新增、更新、无变化、无法匹配、歧义及非法行数量。
- 导入开始和完成时间。
- 备份位置及回滚负责人。
- 页面抽查结果，不少于 5 个达人。
