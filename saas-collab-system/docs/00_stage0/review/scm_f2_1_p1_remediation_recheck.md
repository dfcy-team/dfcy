| 编号 | 复核结论 | 独立复核证据 |

| P1-02 幂等重放依赖活动对象 | 已关闭 | 创建、箱新增/替换、完成/取消、变更提交/批准/驳回均从 `PackingEvent.response_snapshot` 构造冻结引用，不再查询可能已删除或后续变化的活动对象；箱删除后重放和完成后布局变化重放测试通过 |
| P1-03 非空数据反向迁移失败 | 已关闭 | 反向种子操作不再提前删除受 `PROTECT` 引用的冻结标准；在临时 MySQL 8 中创建 1 个引用标准的 `PackingBatch` 后，`migrate packing zero` 成功 |

| P1-05 供应商装箱能力缺少审计 | 已关闭 | 能力创建和更新均在业务事务中写 `packing.capability.update` 操作日志，记录操作者、对象和前后值；创建与更新审计断言通过 |
