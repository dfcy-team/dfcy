## 新增页面能力

新增菜单“API 数据接入 → 平台操作演练”，路由为 `/integrations/platform-drill`。页面按后端数据动态选择平台配置，Shopee 只是当前沙箱参考，不是硬编码的唯一平台。

页面顶部显示六步完成状态和阻塞原因；下方按同一配置上下文展示授权、能力、任务、运行和事件，避免操作员在多个孤立页面之间自行拼接状态。

## 关键动作与安全边界

### 发起授权

- 从配置详情读取平台、允许站点、回调地址和最小 scopes。
- 操作员选择店铺和站点并二次确认后，调用现有 OAuth start 接口。
- 返回的授权地址只在页面展示并支持复制；不使用 `window.open`、`location.assign` 或其他自动外部跳转。

### 刷新与撤销

- 刷新要求 `integrations.store.authorize` 和 `integrations.credential.rotate`；TikTok Shop 明确提交 `confirmed=true`。
- 撤销要求 `integrations.store.revoke` 并进行风险确认。
- 页面不读取、显示或保存明文 Token。

### 创建同步任务

- 只允许从当前授权中已经激活且 `write_enabled=false` 的 ORDER、RETURN_REFUND 或 INVENTORY 能力生成任务选项。
- 新任务绑定当前租户、当前接入配置下的店铺授权；跨租户或跨配置授权由后端拒绝。
- 相同授权与资源的重复任务由后端拒绝。
- 新任务固定为 `manual` 且 `is_enabled=false`，创建过程不调用平台 API；启用和运行仍需到同步任务工作台复核。

### 平台写入

本阶段没有新增平台写接口、写 scope 或自动执行；能力矩阵继续要求 `write_enabled=false`，人工重试继续限定 Mock/沙箱模拟执行。

## 两周演练建议

- 样本：至少 2 个平台配置、3 个店铺授权、6 个只读能力、10 个同步任务和 20 次运行。
- 主指标：操作员从选择配置到定位运行结果或异常处置入口的中位时间低于 5 分钟。
- 护栏一：演练期间新增 `write_enabled=true` 数量为 0。
- 护栏二：页面自动访问 OAuth 地址次数为 0。
- 护栏三：新建同步任务中非默认停用数量为 0。
- 停止条件：跨租户授权可绑定、自动打开外部授权页面、生产平台写调用、或明文凭据进入页面/日志。
