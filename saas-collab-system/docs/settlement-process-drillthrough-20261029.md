# 结算全过程与单据穿透

日期：2026-10-29。本地开发候选，尚未部署。

## 页面入口

- 供应链驾驶舱 → 费用与结算：供应商货款、国内运费、批次货运费、采购定金四类汇总。
- 费用与结算 → 按往来单位对账：复用相同口径，可按国家、类别、单位/单号及全部/待处理/已结清查询。
- 点击汇总或单位排行读取单据；点击单号或“金额过程 / 凭证”进入对应单据；再从来源链接打开采购单、发货单、发运批次或入库单。
- 采购定金过程可以穿透抵扣的发货单；发货单抵扣可以回看原采购定金及凭证。

## 金额口径

- 货款 / 运费：剩余应付 = 当前应付 - 历史期初已付 - 有效逐笔付款 - 有效定金抵扣（仅供应商货款）。
- 采购定金：可用定金 = 有效定金付款 - 有效抵扣；采购未付 = 采购总额 - 有效定金付款。采购未付与发货单未付处于不同业务阶段，不可叠加为总负债。
- 实际付款与定金抵扣分列；冲销保留原记录及反向增减，历史累计仅取最后一版作为期初。
- 国内运费和批次运费分开统计，付款不重新增加商品成本。
- 金额未定时显示待核对；汇总只合计已知应付，并同时显示待核对单据数。未进行汇率换算。

## 逐笔过程

显示登记顺序、业务日期、登记时间、本次金额、付款增减、抵扣增减、本行后累计已付、本行后未付及定金余额，以及账户性质、凭证、冲销原因。

逐笔余额按当前应付重算，页面明确标注这一口径；不将其冒充历史时点应付快照。历史累计付款无法还原的逐笔转账仍显示为期初，保留原历史记录供核对。

## 性能与权限

汇总使用数据库聚合；跨单据明细按需请求，服务端每页20条。查询合计覆盖全部筛选结果，不受当前页影响。凭证和详细付款过程进入单据后加载，不在驾驶舱全量展开。

国家和往来单位筛选不扩大原租户/采购/供应链数据权限；切换国家或账号时清空旧数据并丢弃未完成旧请求。
