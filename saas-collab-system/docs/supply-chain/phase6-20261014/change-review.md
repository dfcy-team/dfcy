# 第六阶段代码审阅索引

候选代码：`.worktrees/supply-chain-phase1-20261012/saas-collab-system`。保留前五阶段全部改动，不涉及正式部署。

## 通知领域

`notification_models.py` 增加发送通道、供应商群绑定、通知部件、发送尝试、回执、核验证据、受控下载授权及共享限流；原 NotificationOutbox 继续关联采购确认事件。`0015–0017` 增量迁移兼容已有记录，`0016` 不授予角色新权限。

`notification_config.py` 负责权限、版本、幂等、托管凭据引用和目标核验；`notifications.py` 负责冻结材料、任务领取、分部件状态、执行结果归并和重试。`worktool.py` 只调用已指定的 WorkTool HTTPS API，以 `titleList` 定位群，文本 203、文件 218；不接入原官方群发通道。worker 与 beat 已连接，一次性 CLI 支持只读 dry-run。

两个事务之间进行网络 I/O。发送前重新检查权限和目标，实际调用使用已领取尝试的 channel。回调不是送达证明；相互矛盾的回执、旧尝试迟到成功会暂停重发。结果查询排除已经观察核实及被新尝试替代的旧尝试。新任务优先于被延期的配置不足任务，避免固定小批量轮询使旧记录挤占队列。

## 供应商商品资料与文件

`supplier_products.py` 只导出描述性商品字段，在确认事件中冻结资料，并为供应商明细补上单品 PDF 和鉴权图片接口。已有商品 SKU 档案继续作为唯一来源，不复制内部成本价、其他供应商报价或库存。

`supplier_product_images.py` 复用既有商品图片的租户目录与公网下载校验，限制类型、大小、像素、并发和处理时长，并重编码缩略图。`documents.py` 在原三张 Excel 表中保留 A–E 列与数量/箱号填写契约，增加内嵌图片和 20 个详细字段；描述自动换行。通知准备时在数据库事务外加载图片，再核对版本、幂等键并原子保存材料。

供应商通过订单权限读取图片 blob，浏览器对象 URL 在换单/卸载时释放。`fetchApiFile` 复用现有登录续期、组织头和受信 API 路径校验；原下载函数继续使用同一边界。供应商明细在后端删除内部参考报价字段。

## 页面和权限

新增 `/supply-chain/notifications` 页面、供应商档案的群绑定抽屉和采购单的通知详情。界面区分通道开关、系统开关、接口受理、工具执行与人工观察，提供明确的缺图、待配置、未知结果提示。通知设置需 `supply.v2.manage` 与 `supply.v2.notify`；只读与授权过期时禁用写操作。

更新权限目录、菜单、前端权限引用清单和端点清单；新增权限不自动分配给原角色。日志脱敏补充 robotId 与回调 signature，异常消息不包含请求 URL 或工具凭据。

## 测试重点

新增通知、竞争条件、商品图片、供应商商品详情和前端图片/文件接口测试；保留前五阶段回归。人工代码审阅发现并修正了切换绑定串用机器人、矛盾回执变成可重试失败、旧未知尝试阻塞新结果查询，以及人工核验后的迟到成功未暂停重试等问题。

未验证项：真实 WorkTool 账号/设备、真实外部群持续频率、安卓端下载和真实商用版本接口、生产托管服务、目标 MySQL 迁移与锁行为。所有这些均在交付说明中保留，未以本地模拟通过替代。
