# 前四阶段完善交付说明

本次补齐销售管理的运营订货单、真实采购拆单、开船前批次调整及取消、物流日期更正。入库继续按已确认范围完成本系统收货流水，库存以第三方仓回传为准。候选代码包含第一至第四阶段累计改动，尚未发布到正式系统。

## 平台运营如何下单

在“销售管理 → 运营订货单”按国家选择现有商品 SKU 和需求数量，保存草稿后提交至采购。该入口独立于平台同步的客户销售订单。供应链模块仍由采购和供应商操作；平台运营在销售管理操作自己的订货需求。

新货可以直接填写数量。周期或季节订货先选择销量周期、目标库销比及是否计入在途库存，再生成建议；有效正数建议带入数量，运营可以人工修改后保存。建议会显示销量、可用库存、在途库存、来源快照、同步批次及生成时间。改变国家、商品或计算参数后，旧建议失效，需重新生成。

计算公式为 `max(0, ceil(周期观察销量 × 目标库销比 − 可用库存 − 选计在途库存))`。销量采用授权国家内店铺本地日期中创建、且在周期结束前已付款的有效订单；库存取第三方仓最新有效来源。周期最多366天，最晚到昨天。比例支持0.0001至100、最多四位小数。

当前建议尚未扣除退款，采集覆盖需要人工复核。缺少库存或销量、存在未映射明细或来源不完整时，不提供建议数量，页面保留该行和原因。零建议不需要订货；运营移除无效或零建议行、重新预览有效商品后再保存，不能把数据缺失当成零库存下单。

已提交内容不可修改，详情显示已拆数量和剩余需求。没有有效采购分配时可以取消已提交需求；已有分配时系统提示先处理相应采购草稿。取消历史保留。

## 采购如何拆单

在“供应链协同 → 采购协同”的运营拆单页签选择已提交需求，填写供应商、本次拆分数量、可选价格和备注单号。每次生成一张对应国家、一个供应商的采购草稿。一条运营明细可以分多次拆给不同供应商，但累计有效分配不能超过需求数量。

留空价格时引用现有采购价格依据；采购可以在拆单时填写价格，也可以在采购草稿中继续调整价格、日期和备注。运营来源草稿的国家、供应商、SKU及数量固定，改变分配需取消草稿后重新拆分。取消草稿会释放对应需求；已下单的采购单不能用草稿取消动作释放需求。

手工创建和文件导入采购继续可用，不要求先有运营订货单。备注单号仍是可选业务备注，允许重复，不替代系统唯一单号。

## 集货与入库的完善

未开船的有效批次可以增减同国家发货单，或整批取消，操作必须填写原因。成员变更会校验批次及各发货单版本；不能将已属于其他有效批次的发货单重复集货。移出或取消后，发货单重新成为可集货候选，原关联及原因仍保留。

开船后不能调整成员或取消批次。开船、到港、到仓的已记录日期可以按实际回执更正，必须填写原因，时间先后关系仍受检查，状态不会倒退。更正由批次自动带给发货单；不会更改已确认入库的数量和收货流水。

批次到目的仓后，选择国家对应的有效仓库生成入库草稿，采购核对实收及差异后确认。本系统只记收货流水，第三方库存继续以其回传为准。这是本期已确认口径，外部库存写入不作为前四阶段的待补缺口。

## 权限配置

运营入口注册独立菜单及查看、维护权限，迁移不会自动把采购账号变为运营账号，也不会自动授予新菜单。授权仍在现有角色权限页面完成。

按国家限制时，在页面选择“站点/国家”；内部统一引用国家档案ID。采购拆单还需选择已授权供应商。仅有供应商范围，不会自动获得尚未分配供应商的运营需求。租户内全部范围可查看全部已提交需求；历史“本人”范围只查看本人创建的数据。查看范围不会扩展维护范围。

运营国家资源与客户销售店铺资源分开处理，店铺报表的全部范围不会扩大运营订货权限。供应商门户不能查看或操作运营需求，也不能访问内部批次或入库写接口。
