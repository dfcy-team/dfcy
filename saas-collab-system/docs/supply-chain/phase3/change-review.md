# 第三阶段改动审查

审查范围为供应商发货写入、私有附件下载、联系人创建与维护，以及两种登录入口的前端接入。第一、二阶段已有改动保留。

独立只读审查未发现明确的跨租户、跨供应商、采购数据范围、供应商改价或文件下载权限绕过。发现并修复两个问题：发货 PATCH 缺省字段会覆盖日期备注；联系人 PATCH 默认值会清空姓名并恢复停用状态。新增局部更新回归验证修复。

根代理整合时还修复了供应商页面缺少新建入口、供应商已提交单显示采购按钮、分页总数读取、空价格误转 0、上传覆盖未保存商品、写失败重试换键、价格输入类型和格式异常导致服务器错误的问题。通过前端挂载测试、实际浏览器、后端字段验证与事务回归验收。

保留边界：供应商可以看采购单已约定价格，不能读取系统参考报价或修改发货单内部价格；附件移除保留历史。文件内容使用有大小限制的私有数据库适配器，正式部署检查连接包大小和备份容量。集货批次、入库、费用成本以及外部群自动投递尚未作为本阶段功能发布。
