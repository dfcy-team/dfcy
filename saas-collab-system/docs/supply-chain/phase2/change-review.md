# 第二阶段改动复核

复核范围为采购写入 API、共享档案、价格版本、导入安全、文件权限和新页面与真实接口的连接。

独立后端复核发现两项需要修正的问题：追加较早日期的价格历史时没有推进价格聚合版本，可能容许旧版本继续覆盖；OWN 采购范围可以手工维护共享供应商和报价。两项均已修正并补充测试，独立复核确认关闭。价格历史追加现在推进版本，手工共享档案仅接受 ALL 或匹配的 CUSTOM 供应商范围。

集成复核补充了菜单迁移，更新既有菜单映射并保持角色授权关系，避免只有直接地址可访问而侧栏没有入口。迁移测试确认不创建或变更角色授予。浏览器验收发现 UTC 与北京时间“今天”不一致，已新增供应链业务日期函数；回归测试覆盖北京时间新一天、UTC 仍为前一天的场景。

确认采购、业务事件和通知 outbox 同事务写入；确认文件读取不可变快照。内部和供应商路由分别校验身份和数据范围，MiniApp token 不允许访问。Excel 原始文件和行号私有保存，限制压缩包、行数、公式和失效引用。文件下载和入库、群消息发送之间没有自动副作用。

最终完整后端测试 75 项通过，前端 31 项通过，模型/权限/菜单/构建检查通过。全部测试使用隔离 SQLite 和纯测试资料。目标 MySQL 并发、生产迁移、供应商端提交发货、库存写入和外部群真实投递尚未验收。本次仅交付候选源码，不执行发布。
