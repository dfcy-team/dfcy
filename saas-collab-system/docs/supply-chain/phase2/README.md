## 采购人员可以做什么

候选版本的“供应链协同 → 采购协同”入口包含采购单、供应商档案、供应商价格、货运公司四个页签。商品 SKU、国家和仓库仍复用现有档案。

| 功能 | 实际行为 |
| --- | --- |
| 手工采购 | 选择供应商和国家，添加多行 SKU，填写数量、价格及可选备注单号；系统自动生成唯一采购单号 |
| 价格参考 | 同时显示商品资料价和供应商最近报价，可由采购改价；空价允许暂存，全部补齐后才能确认；零单价有效 |
| 草稿与确认 | 草稿可修改或取消；确认后锁定商品明细，仅允许修改备注单号和备注，并保留操作事件 |
| Excel 导入 | 下载模板、上传、预览校验，校验通过后提交为采购草稿；不会自动下单，重复提交不会重复建单 |
| 供应商档案 | 维护省份、城市、工厂地址、装柜地址、税费点数、备注以及已有联系方式 |
| 供应商报价 | 可手工选商品维护；有价格的采购单保存后自动补充报价和历史；较早日期的历史价格不会覆盖当前较新价格 |
| 货运公司 | 维护省份、城市、地址、唛头、每方费用、税费点数、备注及联系人资料 |
| 采购文件 | 下载包含“采购单、发货数量填写、箱号信息填写”的 Excel，以及每个 SKU 一页的二维码标签 PDF |

建议验收顺序：先补齐供应商资料，手工建立一个采购草稿，核对数量和金额并改价保存，然后确认采购；再下载两份文件，使用导入模板预览并提交一张草稿，最后查看自动生成的供应商报价和价格历史。运营订货单拆分入口待上游适配器接通，本阶段支持手工和文件导入来源。

确认采购会在同一事务中生成通知记录和当时的数量、金额、价格快照。外部投递通道尚未验收，通知保持 `blocked/channel_not_verified`，页面明确显示待接入。没有调用原群发接口，也没有把文件下载或登录连通性当作群消息发送成功。

## 导入和文件规则

模板九列为：导入分组号、供应商编码、国家编码、商品 SKU、采购数量、采购单价、备注单号、下单日期、备注。同一分组生成一张单，供应商、国家、日期和备注信息须一致；备注单号可空、可重复，不能用来代替分组号。

限 `.xlsx` 文件 5MB、1000 行、100 张采购单；拒绝公式、宏、压缩包超限、无权限或失效的供应商、国家及 SKU。数量须为正整数，价格非负并支持四位小数。价格空白时预览读取最近供应商价或商品资料价；两者均为空的草稿仍须补价后确认。预览价格固定在该导入任务内，提交时重新校验引用和权限。原文件、SHA256、分组和 Excel 原始行号保留在租户及创建人范围内。

采购业务日期默认北京时间，配置项 `SUPPLY_CHAIN_TIME_ZONE=Asia/Shanghai`；系统其他模块的 UTC 设置保持原有口径。日期不可晚于业务“今天”。

确认后导出的 Excel 和 PDF 使用确认时的快照，后续备注或档案改价不会覆盖已下单文件的内容。Excel 中的发货数量和箱号页用于线下填写，本阶段没有将填写结果自动转成发货单；后续箱号网页流程仍只需上传附件。下载接口要求登录和相应单据权限，没有公开文件链接。

## 接口与权限

内部接口前缀 `/api/internal/supply-chain/v2/`。列表和选项支持服务器分页、筛选、搜索。写操作必须携带 `Idempotency-Key`；更新须提交 `expected_version`。同键重试不会重复建单，旧版本更新拒绝覆盖。

| 路径 | 方法和用途 |
| --- | --- |
| `purchase-orders/`、`purchase-orders/<id>/` | GET 查看；POST 建草稿；PATCH 修改草稿 |
| `purchase-orders/<id>/confirm/`、`cancel/`、`metadata/` | POST 确认或取消；PATCH 修改备注 |
| `purchase-orders/<id>/excel/`、`labels/` | GET 采购 Excel、标签 PDF |
| `suppliers/`、`suppliers/<id>/` | GET/POST、PATCH 供应商维护 |
| `freight-companies/`、`freight-companies/<id>/` | GET/POST、PATCH 货运公司维护 |
| `supplier-prices/`、`supplier-prices/<id>/history/` | GET/POST 价格维护、GET 历史 |
| `imports/template/`、`imports/`、`imports/<id>/`、`imports/<id>/commit/` | GET 模板、POST 预览、GET 任务、POST 提交 |
| `options/` | GET 现有供应商、国家、SKU、按国家限制的仓库选项 |

权限沿用采购和供应商两种身份。采购使用菜单权限 `menu.supply.supply_chain_purchase_orders.view`、查看权限 `supply.v2.view`、维护权限 `supply.v2.manage` 及既有数据范围。菜单迁移更新入口名称和查看权限映射，保留原菜单授予关系；不会自动授予维护权限。只有查看权限的用户不能改价、建单、导入提交或修改档案。

ALL 可维护租户内档案；CUSTOM 仅可手工维护明确分配的供应商及报价；OWN 不可手工修改共享供应商和报价，已授权的本人采购保存仍记录其来源价格。采购单、供应商文件和所有引用均限定租户及授权范围。供应商已确认采购文件的下载接口已提供，供应商操作页面和登录入口仍在第三阶段完成。
