## 变更范围

组合商品 CSV 的“组合规格”原先只接受“维度编码=规格值”，导致已经在分类中配置的 `1KG+5LB` 等直接规格值在查找规格字典前被格式校验拦截。本版允许单维分类直接填写规格值；多维分类若该值只属于一个已配置的维度，也可直接填写。维度归属不唯一或无法确定时仍须填写“维度编码=规格值”。更新导入界面提示，不改变现有编码生成及服务端校验规则。
