## 变更范围

1. 顶部 TAB 只从当前用户可见的左侧菜单项生成。
2. 页面内按钮打开的详情、编辑和操作页不再新增 TAB，也不占用用户的 TAB 上限。
3. 菜单子路由继续在右侧展示，并保持所属左侧菜单 TAB 为选中状态。
