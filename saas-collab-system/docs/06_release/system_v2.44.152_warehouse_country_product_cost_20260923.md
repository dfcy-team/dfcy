## 本版范围

1. 成本版本以租户、SKU、**具体仓库**和生效时段为维度；同一 SKU 在同一时期可以因仓库不同而有不同成本。新增版本保留历史，不直接覆盖旧金额。原有无仓库记录保留为历史数据，不自动分派到新仓库。
2. 人工维护、系统生成回填、按时点查询和每期导入均须明确仓库；导入模板增加必填“仓库编码”，继续支持“SKU 编码/旧 SKU 编码二选一”。预览与异常反馈按 SKU＋仓库定位。
3. 商品成本页面显示仓库及所在国家，支持仓库筛选和成本变化历史；系统回填必须先选择仓库。成本查询在指定店铺时校验**仓库所在国家与店铺所在国家一致**，不以国家代替仓库选择。
4. 样品履约的 SKU 成本快照必须指定具体仓库并校验店铺国家一致，按该仓库和业务发生时点取成本；已有快照及历史版本不得被新成本覆盖。
5. 数据库新增 `ProductCostVersion.warehouse` 与 `SampleItem.warehouse`；PostgreSQL 已确认成本的时段互斥约束拆为“同仓库”和“历史无仓库”两组，并增加按仓库/时点查询索引。
