# Shopee 本地调用与入库检查（2026-09-10）

## 范围

- 基线：V2.44.83 / `338085e` 加现有本地工作区增量；未覆盖其他改动。
- 本地前端 3001、后端 8002（DEBUG=False）、Docker MySQL `saas_collab_live_local_20260909`。
- 使用当前登录用户对应的租户与数据权限，验收专用 Shopee 接入和店铺。
- 仅 Shopee 只读请求与本地入库测试；没有平台改价、库存修改、上下架、虚拟机或阿里云发布。

## 已修复

1. Shopee 订单/退款读取错误依赖公共凭据中的旧合同开关；商品请求仍依赖旧 API 主机字段。改为读取已审批运行配置，与 OAuth 一致，不允许旧配置绕过审批。
2. 首次 OAuth 授权创建记录时未保存平台返回的到期时间。传递并保存该时间；旧授权已通过登录页面刷新令牌一次，到期时间实际落库。
3. 订单标准化合同丢失平台商品 ID、规格 ID 和行状态。真实订单明细因必需商品 ID 为空而保存失败。保留这三个已有来源字段，不虚构商品映射。
