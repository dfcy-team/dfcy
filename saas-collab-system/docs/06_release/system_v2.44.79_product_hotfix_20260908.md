## 改动与已确认原因

1. 商品明细前三列固定顺序为“序号、选择、图片”。仅移动模板会被 Element Plus 的 fixed 列排序覆盖，因此前三列均固定在左侧。
2. 商品主数据和明细加载基础档案颜色接口，按分类 ID 合并权威颜色，包含恢复默认色。不以跨一级目录可能重复的二级编码覆盖颜色。
3. SKU 编码服务允许分类规格字典中已有的传统字符串值，如 `90X200CM`、`2PCS-1`。原单位正则错误拒绝这些已配置值，已用生产数据形状复现 422。字典外非法值仍拒绝。
4. SKU 失败提示显示具体校验内容，保留对话框和用户选择；成功数量直接读取顶层 created/skipped，不再错误解包 results 第一项。
