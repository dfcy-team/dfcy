# 每日多时点排程（2026-10-23）

每日同步计划现在支持 `local_times`，最多 8 个 `HH:MM` 时点。服务端按本地时区排序并逐个计算下一次运行；旧的单时点 `local_time` 仍然有效。数组为空时回退到 `local_time`，显式更新 `local_time` 会清除多时点配置，切换到非 daily 计划也会清除它。漏跑仍遵循原有 `run_once` / `skip` 策略。

回退代码前，先将所有使用多时点的业务计划改回 `interval`（例如每 360 分钟），并确认配置已生效。旧版本不识别 `local_times`，不可在保留多时点配置时直接回退代码。
