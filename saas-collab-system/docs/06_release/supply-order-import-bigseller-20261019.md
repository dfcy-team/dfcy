# 采购录入、导入及 BigSeller 批次导出改进

日期：2026-10-19（Asia/Shanghai）。本批以冻结 V253 候选 d47e359a 为基础新建分支；不修改 V253 提交，不自动发布虚拟机或登记新版本。

## 操作变化

1. 采购草稿每行 SKU 候选排除其他行已选商品，本行当前值保留可读。前后端新建/编辑都禁止重复 SKU，并列出重复行号；Excel 原行号继续保留。
2. 导入同时匹配新编码、商品旧编码及已生成旧资料映射；多商品歧义拒绝，不静默挑选。错误区分缺填、不可访问供应商、国家无效、SKU 不存在/停用/组合商品、数量、价格、日期与分组内重复。模板前五列标 *，旧模板仍兼容；弹窗提示错误总数与前20条明细，错误时禁止部分提交。
3. 附件等价用例：HY118-Yellow20、Pink100、Green10、Black170属分组1；Black100属分组2，合计400件、2张草稿。跨组重复允许，同组新旧码解析为同SKU则拒绝。
4. 采购 Excel 商品部分仅保留供应商使用的图片、新旧 SKU、名称、采购数量/单价/金额，以及实际维护的品牌、规格、颜色、尺寸、材质、单位、包装尺寸重量体积；整列未维护则移除，不再输出内部 SPU/形态/卖点/分类等字段。三工作表及数量填写列位置保留。
5. 集货展开商品行显示原发货量、累计已集货、剩余可集货；已有批次增加本批量。数据缺失显示 —，不冒充0。
6. 批次详情“导出 BigSeller 采购单”沿用用户提供的中文模板，SKU页51列表头、选项表、数据验证保留。临时编号=批次号，供应商=国内供应商；只取有效本批分配，合并同SKU数量。默认旧SKU优先，也可选新SKU；缺旧码回退新码，不同商品的同码冲突拒绝。单价按该批各来源发货单采购单价加权至4位，任一未定价则留空，CNY/汇率1；未直接填入后续运费/清货费或成本价，避免重复计费。原运单号带出，其余未维护的模板可选项留空。取消批次、无分配、错误编码方式拒绝。

## 性能与验收

导入 SKU 分块查询（每400码），已生成旧码一并批读；参考价按供应商/SKU组合批量查询。12行空价用例固定2次SKU及1次供应商价查询，无延迟字段逐行加载。BigSeller 取有效分配及商品单次关联查询，点击时生成文件，不在列表预加载。下载沿用内部登录与整个批次供应商数据范围校验，供应商账号拒绝；不创建BigSeller采购单，不修改业务数量、结算或库存。
