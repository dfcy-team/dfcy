# 广告报表规划与占位修订

用户要求广告报表保留规划与占位。此前 V2.44.201 将三个广告菜单隐藏；本次恢复原有授权用户的入口，使用规划占位替代未接入时的查询与空图表。

| 菜单 | 所属模块 | 原权限 | 内容 |
| --- | --- | --- | --- |
| 广告总览 | 经营分析 | analytics.view | 账户/店铺日趋势、曝光点击、消耗、归因订单和销售、效率指标 |
| 广告投放分析 | 经营分析 | analytics.view | 计划、广告组、广告、商品/SKU和素材；关键词/搜索词按平台实际支持开放 |
| 广告费用对账 | 财务中心 | finance.view | 报表消耗、账单扣费、退款/调整、税费、财务入账及各环节差额 |

占位页显示“待接入”“未采集”，提供报表规划、指标口径和接入条件页签。广告数据尚未接入时不请求广告报表、不生成零值或模拟结果，真实查询、导出、穿透及 BI 数据执行保持未开放。预算、关键词及投放状态不属于本次能力。

接入顺序为日汇总总览、计划和商品明细、平台可提供的搜索词/素材、账单及财务核对。广告授权和账户/店铺映射、来源覆盖、归因窗口/转化定义、时区、币种、SKU映射和费用调整口径须逐项核验。不同归因版本和币种分开；零分母或缺字段显示不可计算。

后续 BI 复用报表中心的维度/指标拖拽、透视、图表、个人与共享配置，并按当前查看者权限查询。穿透保留日期、币种、账户和归因版本；平台归因销售不能直接与业务订单销售相加。

本次没有新增迁移、数据接入、同步任务或角色授权，原路由和权限目录保留。菜单恢复仍通过原权限和模块禁用检查；只修改广告占位展示和原隐藏菜单测试契约。

指标资料：[Amazon Ads ACOS](https://advertising.amazon.com/library/guides/acos-advertising-cost-of-sales)、[Amazon Ads ROAS](https://advertising.amazon.com/library/guides/return-on-ad-spend-roas)。接入其他平台时以该平台可用字段和归因定义适配。

验证：完整前端 866 项测试通过，生产构建通过，权限快照核对一致（108 菜单、142 路由）。本地浏览器三页在 1440×960 和 390×844 均通过，九次页签切换成功，广告 API 请求及控制台错误均为 0。验证使用本地验收模式，没有已接入广告数据；发布状态以受控发布通道回执为准。
