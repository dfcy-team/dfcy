## 变更范围

1. 组合商品 CSV 导入模板增加可选“组合规格”列，格式为 `维度编码=规格值`，多个维度用分号分隔；现有未含该列的文件继续按无规格导入。
2. 导入时按末级分类的规格维度校验编码，逐行提示未知、重复或空规格值。有效规格提交到服务端，由现有 SKU 编码规则生成带规格的组合 SKU；无规格时保持原编码形式。
3. 组合商品创建接口接收可选 `spec_values`，沿用普通 SKU 的规格维度校验和编码逻辑。
