# 本地销量报告与订单报告

- SKU 销售参考 BigSeller `/web/statis/items.htm`：店铺／商品 SKU 汇总切换、平台门店多选、日期与 SKU 模糊搜索、商品行汇总趋势、产品明细、可选列、后端全量排序和分页。
- 销售总览参考 `/web/statis/order.htm`：最近两个有数据日期的订单概览、订单汇总趋势、按日明细与列设置；移除总览中的 SKU／门店明细切换。
- 不恢复独立币种和日周月控件；顶部统一筛选，分币种展示。
- 新 SKU 查询使用 `report=true`，原有 API 默认行为不变。商品 SKU 仅合并同一内部 SKU；未关联记录按来源店铺和编码隔离。汇总订单数使用集合去重，不将明细行订单数相加。汇总在分页前计算，SKU 搜索同时作用于汇总与趋势。
- 非取消商品指标排除取消订单；全部商品指标保留取消订单。退款来自退款商品行；订单报告退款来自退款事实。两类金额不混用。
- 订单概览不是固定昨天／前天零补齐，而是所选范围最近两个有数据日期。来源不完整时不宣称无业务。
- 未增加客户、包裹、毛营收、补贴、图片、同期涨跌等无可靠来源字段。导出维持销售事实明细，弹窗明确不等同于报告聚合表。
- 仅本地代码与服务更新；未执行平台同步、修改事实或云端部署。

验证：前端 7 文件 50 项测试；后端报告、销售管理、店铺报告 15 项测试；Vite 构建；浏览器 SKU 分组切换与订单概览真实数据检查。
