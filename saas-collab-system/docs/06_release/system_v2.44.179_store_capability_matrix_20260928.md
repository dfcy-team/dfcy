# V2.44.179 店铺能力矩阵按 API 来源区分

## 正式环境问题

同一 Shopee 店铺可以分别绑定商城销售 API 与广告 API 接入配置，凭据与授权记录独立。能力矩阵此前直接列出授权记录，只展示店名和授权编号，所以同店铺出现两项。阿里云只读审计显示，配置 #4 为商城生产配置、#31 为广告生产配置；截至审计时有 7 个店铺各具备两种有效授权。原有商城授权含能力配置，广告授权尚无能力配置。两类授权都应保留。

## 修改

- 店铺列表按店铺分页，每家店铺仅出现一次；进入店铺后，在每项能力行选择商城销售或广告 API 连接，显示接入配置名称和授权编号。
- 能力代码后显示中文名称。店铺档案里的能力矩阵弹窗也采用相同标注。
- 商城 API 可配置商城能力；广告 API 仅提供广告与报表能力。后台校验接入配置、店铺、权限范围与只读边界。
- 调整能力来源时，在同一数据库事务中停用同店铺该能力的旧来源。原授权与能力历史行保留。

## 发布边界

从正式环境当前版本累计发布至 V2.44.179；先在虚拟机发布并验收，再发布阿里云。发布不导入虚拟机业务数据，不删除授权，不覆盖凭据，不启用写入能力。正式发布前重新核对线上父版本、迁移计划与备份。
