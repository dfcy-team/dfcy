## 变更范围

1. 内部系统数据接口授权由单层资源平铺调整为“业务模块 → 数据块 → 字段”三级最小授权。
2. 提供基础档案、商品刊登、采购与供应链、销售与库存、达人协作 5 个业务模块；模块下共配置 14 个只读数据块。
3. 选择业务模块后仅展示该模块的数据块；选择数据块后仅展示该数据块允许读取的字段，取消模块时自动清理已失效的数据块和字段选择。
4. 后端同步扩展数据块及字段白名单校验，只保存明确选中的数据块与字段，不把模块选择解释为整模块全量授权。
5. 财务、用户权限、系统配置等敏感数据不在本版本开放范围；业务数据端点 `/api/internal-readonly/v1/` 仍未上线。
