# 运营订货国家参考清单与平台分析

本次将周期、季节订货扩展为：选择国家和历史销售参数 → 生成参考清单 → 跨页勾选普通商品 → 加入订货明细并重新生成有效建议 → 人工复核数量 → 保存草稿 → 提交采购。新品仍可手工录入。

参考清单按当前国家的授权普通商品目录分页，尚未限定为该国已有销售/库存事实的商品。缺数据保留未知和问题提示，不用零替代。筛选“建议订货／无需订货／待核对”仅作用于当前页，页面明确标注，不声称已对全目录计算排序。

默认国家汇总，不区分平台。切换按平台分析后，所选平台的销量、日均销量、占国家销量比例另列展示。平台选项来自有权限的当前国家活跃店铺。国家建议订货量不随分析平台变化：共享WMS可用库存、按期有效到货、开放运营需求仍只在国家计算中扣减一次。平台视图选中商品后，最终预览调用不传平台过滤，重新计算国家需求；不生成平台独立库存或独立采购需求。

周期和季节目前共用历史库销比公式；季节参考销售期间由运营手选。活动、需求期间等仍是单据元数据，本次未新增季节增长预测或平台专属库存分摊。页面有明确说明。

菜单首次加载不请求参考计算；参考组件按需异步加载。只在用户点击生成或翻页时请求，每页最多20个商品；图片沿用懒加载。平台模式只增加一批当前页销量聚合，不逐SKU查询。空页跳过计算；每张建议单最多勾选100个商品；筛选参数变化清除旧结果，晚到响应丢弃。最终建议保留原有权限、幂等令牌、需求变化校验及拆单流程。

该变更为本地开发成果，无数据库迁移；未部署虚拟机，未自动新建真实订货单。合入发布时需仅提取本次增量，保留主干既有经营汇总性能优化。
