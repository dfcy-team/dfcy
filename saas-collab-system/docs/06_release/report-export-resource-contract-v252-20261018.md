# V2.44.252 报表目录资源契约修复候选

## 问题及行为

已有明确 reports.sales / reports.inventory 资源策略的用户可以读取基础数据集，但导出目录仍只校验旧 reports.view 的 report_types，导致混合历史配置返回 DATA_SCOPE_INVALID。自助导出又重复旧校验，且 reports.view 的源快照未包含显式资源策略。

候选让目录从现有、已通过数据集和业务权限校验的显式策略投影类型；未获得合法替代策略的无效旧范围仍拒绝。创建与下载继续使用独立权限、类型限制、数据过滤及审计。自助导出复用统一的数据集授权，并将对应报表资源策略纳入源快照和异步任务指纹。

目录类型可见不等于历史数据可见。对无效旧范围，历史恢复仅限本人、本租户、精确数据集且 source_scope 与当前权限快照完全一致的自助记录，过滤发生在分页前。旧财务配置、其他用户/租户、缺少快照或范围变化后的记录均不恢复。旧类型范围合法的历史查询路径保持原实现。

显式资源快照收窄或撤销后，已生成文件、既有下载链接及任务指纹均重新校验。旧文件如果未保存当前所需资源快照，会被保守拒绝，需要按现有权限重新生成；不会修改旧审计记录或回填授权。
