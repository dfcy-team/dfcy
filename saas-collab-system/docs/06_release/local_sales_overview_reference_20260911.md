# 销售总览参考图调整（本地）

## 范围

- 仅调整销售总览，沿用既有登录、权限、筛选接口及订单事实数据。
- 紧凑筛选区、横向滚动销售指标、时间趋势／区间统计、日／周／月切换、币种切换及指标图例开关。
- 门店概览及详情保留；来源、质量和统计口径采用可展开说明。
- 不增加没有接口支持的仓库、分类、组合 SKU 筛选，不填充毛利、环比等演示数据。

## 数据口径

- 金额按币种隔离，所有趋势日期均保留，不再截取最近 7 个数据日期。
- 周以周一为起点，月使用自然月；首尾区间仅汇总筛选范围内已返回日期。
- 缺失指标保留为空，不补零；零值和负值正常绘制，区间明细提供完整数值及排序。
- 汇总包含取消订单，趋势销售额排除取消订单；原有后台计算口径不变。

## 验证

- 6 个前端测试文件共 40 项通过，覆盖聚合、币种隔离、零值／负值／缺失值、图例、键盘切换、筛选请求、错误清空及其他销售页面回归。
- 生产构建通过。菜单权限快照保持一致；仅有既有 VueUse PURE 注释提示。
- 本地登录会话验证日／周统计、区间明细及最终页面；1034px 视口下页面没有横向溢出，指标栏和宽表在自身容器滚动。
- 未触发平台同步、导出或业务数据写入，未发布到远端。

- 总览中增加 SKU 销量明细，沿用 `sales_management.skus.view` 权限及现有分页接口；支持 SKU 模糊搜索、20／50／100 条分页和展示列选择。搜索仅影响明细，不改变总览金额。
- 保留门店概览切换；不模拟商品图片、测评订单标记、跨店商品 SKU 聚合或环比指标。
- 说明门店时区筛选与来源业务日期分组的边界差异；未改后台统计口径。
