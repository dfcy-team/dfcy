## 变更范围

1. 旧组合关系迁移直接支持 BigSeller 横向 `.xlsx` 和 `.csv`，兼容标准纵向关系模板。
2. 表内全部组合 SKU 均作为旧组合候选，不再使用 `ZH` 前缀作为组合商品判定条件。
3. 组合 SKU 和成分 SKU 同时支持按旧 SKU 编码、当前 SKU 编码精确匹配。
4. 旧组合 SPU 改为可选；未提供时从已导入的组合 SKU 自动反查当前或旧 SPU。
5. 横向文件的多组成分自动展开为关系行；空值、非法数量、未匹配、多重匹配、自引用和重复成分均阻断确认。
6. 预演统计展示完整关系总数和阻断总数，明细仅返回受控样本，避免大文件响应膨胀。
7. SKU 匹配改为租户内批量查询，避免大批量文件产生逐行数据库查询。
