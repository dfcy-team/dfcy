- 送样详情兼容 VM10 响应结构，避免详情字段整体为空。

- 移除送样销售价格展示、销售价格匹配和“流转”操作；仅保留数据库采购成本。
- 采购成本读取 `ProductSKU.purchase_price`，按业务确认统一以人民币 CNY 参与达人绩效投入统计。
- 人工送样状态仅允许“已完成”和“已取消”；筛选项移除旧的处理中、创建中和空白状态。
- 建联任务完成后仍允许继续创建送样。
- 任务完成进度只统计有效履约状态，并按规范化达人身份去重。
- 统一送样创建、完成、逾期、拉黑重算的 tenant-first 锁顺序，降低并发异常和死锁风险。

## 数据兼容与回滚

- 本候选不包含 `influencers.0015`，不批量改写历史归因快照，也不执行不可逆数据迁移。
