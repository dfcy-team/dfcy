## 增量范围

1. 商品 SKU 与旧商品档案增加可空库存属性：`virtual`（虚拟商品）或 `physical`（实体商品）。不回填历史数据；编辑未设置记录时界面预选实体商品，只有保存才写入，已有虚拟商品保持原值，明确勾选清空才删除。
2. 库存分析增加“包含虚拟商品”选项，默认包含以保持原口径；关闭后在选定最新快照之后排除明确标记为虚拟商品的关联 SKU，明细、分页、汇总、风险统计、映射率和趋势使用同一筛选。未设置属性及未关联记录保留。
3. 平台商品明细页面增加店铺商品/仓库 SKU 切换。仓库 SKU 直接读取当前租户和权限范围内的极风库存快照，不新建仓库商品表，不复制数据库或配置。
4. 仓库 SKU 映射只在明确确认且具备 `integrations.product_mapping.confirm` 时更新同仓库、同站点、同来源 SKU 的历史 `internal_sku`；仓库锁、历史集合乐观校验、双权限范围校验和审计处于同一事务，审计失败整体回滚。
5. 后续库存同步优先继承已确认的仓库历史映射；无历史时继续执行卖家编码冲突与唯一精确匹配。来源 SKU 的历史匹配和最新分组按大小写精确处理，兼容生产 MySQL 的不区分大小写默认排序规则。
