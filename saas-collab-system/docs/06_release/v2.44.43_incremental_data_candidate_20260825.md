## 发布范围

本候选只登记以下菜单及其 tenant 1 数据联动：

1. 店铺档案：店铺身份、平台、国家、币种、时区、授权映射和同步状态。
2. 仓库档案：仓库、国家、库存授权、同步运行和库存事实关联。
3. 销售管理：销售总览、订单、退款退货、门店销售、SKU 销售、导出和数据质量。
4. 经营决策：Vue Router 菜单直达六个 Vue 原生页面，复用现有登录、RBAC、数据范围和 CSS 结构；不再加载 Next.js 独立工作台或独立样式。
5. 经营分析：Commerce/WMS 真实字段、动态筛选、数据新鲜度、销售与库存维度联动。

API 数据接入、凭据托管、同步任务、同步运行和业务事实的变化仅作为上述五个模块的数据链路支撑，不调整其他业务菜单。

## 数据与结构增量

- 统一使用 tenant 1 的本地平台、国家、店铺和仓库档案作为授权映射主数据。
- 销售事实复用订单、订单明细、退款退货和退款明细；库存事实复用库存快照，不创建平行业务事实表。
- 新增正式只读 Commerce/WMS 合同、同步工作区、事实幂等写入和增量导入命令。
- 数据新鲜度、来源、质量状态和刷新时间由同步运行及事实记录联动计算。
- 包含基础档案 `masterdata.0003` 至 `masterdata.0008`、`reports.0007_real_export_files` 与 `permissions.0032_seed_live_readonly_sync_permission` 共 8 项 Django migration。
