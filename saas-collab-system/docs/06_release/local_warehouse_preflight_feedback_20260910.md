# 极风授权预检查反馈修正（仅本地）

## 实际原因

只读核查 THCS 的当前授权绑定 5、接入配置 4：network_enabled=false、sync_read_enabled=true、sync_write_enabled=false、contract_approved=false；配置状态 verified、环境 production。运行环境允许受控联调且开启全局只读功能，但不等于当前接入配置已获准访问平台。

bootstrap_consumed_at 为空、未取得仓库 OAuth 身份。授权服务在预检查失败后尚未进入凭据读取及一次性 Token 消费步骤，不能把本次错误判定为极风拒绝 Token。

## 本地改动

- 通用异常响应保留列表型校验错误的提示；字段型错误显示“提交内容校验失败，请检查字段提示。”并保留原字段明细，不再返回占位文字 error message。
- 极风预检查一次列出配置级网络审批、只读能力、接口合同的缺失项，返回固定中文提示；不复制平台原始响应或凭据。
- 保留所有网络、模块、环境、状态、合同、只读及禁止写能力检查。没有更改审批状态或重复执行真实授权。

## 验证与限制

新增测试修改前 4 failed / 8 passed，修改后相关快速测试 12 passed。验证预检查失败时不调用平台、不读取凭据、不消耗一次性 Token，以及批准网络后合同门槛仍有效、启用写能力仍被拒绝。

完整定向回归：预检查、统一异常响应、极风凭据、OAuth 脱敏诊断及授权事务共 91 passed（131.18 秒，隔离 SQLite，禁止外网）。确认无 pending OAuth 后仅重启本地 8002 后端加载修复，3001 地址不变。

本次仅修复反馈和诊断，不能代替配置管理员完成网络访问审批及极风接口合同确认；真实授权仍处于配置阻塞状态。无数据库迁移、无虚拟机或阿里云发布。
