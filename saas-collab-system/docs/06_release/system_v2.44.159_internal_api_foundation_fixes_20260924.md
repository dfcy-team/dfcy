2. 基础档案—组合商品：资料字典加载完成即启用导入确认，不再依赖先创建一条组合 SKU。
3. 基础档案—商品导入：按本次实际创建的记录 ID 生成新增商品，避免混入已有档案；旧档案导入后补齐系统内部 SKU 编码。
