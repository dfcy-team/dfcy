# 本地同步任务启用与真实运行入口

## 使用方式

在“API 数据接入 → 同步任务”中，先对指定任务点击“启用任务”并确认，再点击“执行一次真实同步”并确认。顶部“查看运行记录”用于核对执行状态和落库结果。队列受理不代表同步成功。

启用只更新当前任务，不立即采集。当前 7 个任务都是手动任务，本次保持停用，未运行真实平台同步。模拟入口仍仅允许独立 Mock 任务。

## 安全与校验

- 启用沿用管理权限、租户及数据范围校验；真实运行需要独立的 `integrations.run_live_readonly` 权限。
- 启用和入队前检查适配器、授权有效期、Token 引用、只读能力来源及既有配置审批；不读取密钥或调用平台。
- 运行中不允许启用、停用或重复运行；真实入口拒绝 Mock 任务。
- 前端确认期间即锁定操作，同一任务运行版本复用幂等键。队列连接异常只返回脱敏的不确定结果提示。
- 未修改平台写入权限、合同审批或现有授权。

## 本地执行环境

- 后端仍为 `127.0.0.1:8002`，页面为 `127.0.0.1:3001`。
- 新建专用 Redis 容器 `saas-collab-live-local-redis`，仅监听 `127.0.0.1:6381`，使用独立数据卷。未连接已有业务队列。
- 本地启动脚本连接该 Redis，独立 worker 仅消费 `local-live-readonly` 队列，单进程运行；没有启动 Celery Beat 或定时调度。
- 受控出口仅增加回环地址的 6381 端口，外部 HTTPS 域名白名单保持不变。
- 启动脚本在工作区上级 `.codex-tmp/start-live-backend.py` 和 `.codex-tmp/start-live-worker.py`，沿用已有凭据加载方式，不含真实凭据。服务本次已启动，未配置开机自启。

- 后端 60 项隔离测试通过：任务控制、Mock 隔离、同步框架、能力门禁及缺失任务预览。
- 前端 32 项测试通过：任务交互、权限、同步健康、缺失预览及请求认证重试保护。
- Django 系统检查无错误。
- 页面核验 7 个启用按钮可见、真实运行按钮在停用状态禁用；已打开并取消启用确认弹窗，没有启用任务。
- 独立 worker 控制通道 ping 成功；数据库启用任务为 0、运行记录为 0。
- 实际生效只读同步开关已开启。Shopee 商品/订单/退款、TikTok 商品、极风库存配置预检通过；TikTok 订单/退款仍需接口合同审批。本次没有进行真实采集或落库验收。
