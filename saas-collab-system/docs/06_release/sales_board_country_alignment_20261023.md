# 实时数据大屏：国家范围与经营口径对齐

基线：阿里云累计 V2.44.289（0d3a385490a26f640b7be4aa373fb21759aa35d2）。本轮为本地候选，未发布。

## 本轮实现
- 国家／站点筛选复用现有授权店铺目录，不新增筛选请求；平台变化重置国家和店铺，国家变化重置店铺。
- 国家参数 region 随查询及订单下钻传递，采用现有销售查询国家规则。
- 店铺贡献排行增加国家标识。
- 整店 ROI 采用有效非取消订单销售额／广告消耗，沿用广告费率完整性门槛；零花费或数据不完整显示不可用，不是利润 ROI，也不是广告归因 ROAS。
- 保持五维度本地切换、懒加载、隐藏暂停和单请求轮询；不变更菜单或权限。

## 对齐结论与后续依赖
- 销售工作台候选 6e2f30fd 使用 region、日期和币种，但经营入口当前只消费日期跳转参数；完整店铺／国家下钻待工作台契约支持后接入，避免跳转后静默扩大范围。
- 当前租户汇率只有最新快照，历史每日汇率未持久化。不能把当前汇率用于历史报表并称为业务日折算。人民币完整汇总、跨币种全量排行需独立实现及验收；不得在浏览器拼接各币种 TOP10。
- 正式页面 MYR 当日样本显示订单行未映射内部 SKU，库存和系统商品分类无法补全。需要核查订单行 internal_sku/internal_spu 映射与同步来源；不能直接自动改绑或把缺失库存补零。
- 昨日对比、下降全量排名、诊断快照、工作台原因详情接入仍为后续批次；今日同段广告比率等待同段数据证据。
