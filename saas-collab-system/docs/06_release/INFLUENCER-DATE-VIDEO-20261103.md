# 达人创建日期筛选与视频履约关联

## 范围

- 建联任务、送样履约新增创建日期范围；接口参数 created_from / created_to，格式 YYYY-MM-DD。
- 北京时间 UTC+8，包含结束日期全天，使用 datetime 范围过滤，不改变租户、店铺、权限和分页边界。
- 重置清空日期，选择日期回到第一页。
- 送样状态列显示已关联发布视频数量。
- 视频同步命令增加显式 --reconcile-fulfillment 参数；只有当前店铺所请求日期均成功或已完成，才调用现有注册视频核验服务。

## 状态规则与限制

仅已注册 VideoResult 与 API 视频的租户、店铺、视频 ID、达人身份一致，且送样商品、发布时间和唯一候选验证通过，才更新送样状态为“已发布”，并由现有服务记录审计、重算建联进度。最终“已完成”不是仅发现视频即可设置。

没有已注册视频、身份不明确、时间不明确、多条候选的记录不自动修改。本版不解决 API 视频的所有身份补全，不应宣传为全部历史逾期自动完成。

不加 --apply 时只检查；不加 --reconcile-fulfillment 时保持原同步行为。关联失败单独报错，不回滚已成功的视频入库。

## 发布注意

本次未修改阿里云文件、生产数据、定时任务、权限和账号。上线需先比对生产热修复差异，不能用旧版 views.py 或整套前端直接覆盖现场。

先用单店 dry-run 查看匹配/阻塞计数，再明确开启该店正式关联。夜间任务需另行添加参数，本提交不会自动开启全店状态更新。
