2. 趋势先定位最近 14 个有数据的 UTC 日期，只聚合该范围内的历史快照；新增 `inventory_snapshot(tenant_id, snapshot_at_utc DESC)` 索引，迁移为 `commerce.0005_inventorysnapshot_tenant_recent_idx`。
3. 前端库存工作台单独使用 30 秒请求上限；其他接口仍使用原全局上限。延长上限只是容错，不视为性能达标证据。
