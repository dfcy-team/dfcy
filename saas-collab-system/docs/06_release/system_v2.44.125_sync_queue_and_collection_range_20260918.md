# V2.44.125 同步排队记录与自然日采集范围

## 版本登记

- 登记版本：`V2.44.125`
- 目标父版本：`v2.44.124-deployed`
- 发布前必须再次核对虚拟机当前版本、主分支 SHA 和最新 deployed 标签一致。

## 发布目标

- 手工真实同步在投递队列前先生成可见的排队运行记录，同一请求编号保持幂等。
- 排队或运行期间阻止重复提交、停用和计划修改；工作进程领取原排队记录，不创建重复记录。
- 订单和退款支持最近 N 个北京时间自然日，或按北京时间指定含结束日的历史补采范围。
- Shopee 单次最多 15 天，其他当前订单／退款客户端最多 30 天；修改范围时清空旧分页位置。
- 修正 Shopee 退款第一页从 `page_no=0` 开始，并在运行详情按北京时间展示实际采集日期。
- 在 LAN HTTP 下使用安全随机源生成同步请求编号，不降级为弱随机值。

## 变更边界

- 数据库迁移：`integrations.0030_syncrun_queued_state`。
- 无新菜单、路由或权限；菜单与路由数量保持 `104 / 136`。
- 保存范围或计划不启用、不停用也不执行任务；固定范围会被后续运行重复使用。
- 不修改平台凭据、生产配置、合同审批或写同步能力。
- 保留 V2.44.122 的 Shopee 根地址回调桥接和现有调度超时保护。

## 验收要求

- 排队幂等、并发阻断、工作进程领取、预检失败闭环测试通过。
- 自然日边界、固定范围、上限校验、游标清理和 Shopee 退款分页测试通过。
- Django 检查、迁移漂移、前后端测试、生产构建与受保护 CI 全部通过。
