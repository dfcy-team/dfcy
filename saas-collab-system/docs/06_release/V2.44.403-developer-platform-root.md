# V2.44.403 开发者平台根路径热修

内部开发对接支持将相对路径 `/` 登记为平台账号级资源。一次申请并批准后，开发者按实际相对路径调用，无需逐条登记业务接口；支持系统尚未接入业务流程的接口。

## 操作

1. 在「授权中心 → 开发者中心 → 内部开发对接 → 接口资源」登记资源，选择平台连接与店铺账号，使用匹配的签名适配器和平台 API 地址，相对路径填 `/`。
2. 新建应用或在已有应用「申请扩权／延期」中选中该平台资源，审批通过后领取开发令牌与接入资料。
3. 调用同一个网关地址，在 JSON 中填写 `path`、`method`、`query`、`body`；页面「调用调试」也提供路径与方法输入。

例如 Shopee 店铺信息只读调用（网关地址中的应用 ID、资源代码取接入资料）：

```json
{
  "path": "/api/v2/shop/get_shop_info",
  "method": "GET",
  "query": {}
}
```

开发端无需安装补丁包；下载更新后的 OpenAPI、Postman、Python、JavaScript、curl 示例即可。平台签名和真实平台令牌由服务端处理。

## 范围

`/` 覆盖所选平台账号的接口路径，不跨账号或平台，不扩大第三方平台授予的权限。现有固定路径资源和旧 `/` 记录保留固定范围，需新登记平台资源并批准才能扩大调用范围。

生产连接保留只读限制；未知 POST、PUT、PATCH、DELETE 等写入请求仍要求启用写入的测试连接。Lazada 当前适配器只支持 GET。平台授权过期、连接关闭、网络目标限制仍生效。未宣称所有平台接口都已真实验证。

## 交付与后续发布

本次是现有容器上的增量热修，后端增加 `0062_developer_platform_scope`。前端在当前线上入口上仅替换开发者页面和更新记录，保留其他线上页面热修。源码分支为 `codex/developer-platform-root-20261109`。

热修文件和回滚备份由发布控制目录保存。普通容器 restart 保留热修；后续使用旧镜像 recreate 会丢失容器内改动，因此正式镜像发布需合入本修复及当前全部热修。数据库回滚保留新增字段，旧代码仍兼容。
