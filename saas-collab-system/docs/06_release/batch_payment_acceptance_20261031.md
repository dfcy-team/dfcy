# V2.44.347 同单位多单付款验收

## 操作入口
费用与结算 → 按往来单位对账 → 选择供应商或货运公司 → 批量申请付款。驾驶舱费用汇总中的“去付款”跳转到相同入口。

批量付款针对供应商发货单货款、国内运费、发运批次费用和入库清关费用。采购定金仍沿用原单申请；不同往来单位、不同收款账户或对公对私性质分别申请。

## 操作流程
1. 选择同一单位的待付单据或费用项目，每组 2—20 项；可跨页选择，每项填写本次金额。
2. 选择该单位的收款账户并填写理由，保存草稿后提交一次审批。
3. 从飞书通知进入系统审批；通过后上传转账凭证，由财务确认整组入账。系统不执行银行转账。
4. 每张来源单据保留分配的付款流水及凭证，仍可查询已付和剩余应付。发生错误时整组冲销并保留追溯，不单独冲销其中一行。

## 必验边界
- 两张同供应商发货单，分别支付部分余额，合计等于批次金额，审批与付款流水均可穿透。
- 同货运公司不同费用项目按对公/对私分开；非所属账户、跨单位、重复明细、非正数、超额金额均拒绝。
- 既有单笔申请与批量申请共用余额占用，提交后不能重复申请相同可用余额。
- 重试不重复建单或入账；任意一行失败整组回滚，取消/驳回释放占用。
- 无来源权限账号不能通过申请列表、详情、审批或凭证下载看到整组信息。
- 财务确认必须有真实付款日期及凭证，其他角色不可代替财务确认。
- 真实环境验证飞书通知链接、附件上传下载及往来单位大数据量查询耗时。
