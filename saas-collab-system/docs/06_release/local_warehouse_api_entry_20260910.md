# 仓库档案与 API 接入入口调整（仅本地）

依据用户最新要求，沿用既有后台组件与 impeccable 的产品界面约定，不做视觉改版。

- 新增/编辑仓库只维护档案，不显示接入配置、Email、Token 或外部仓库编码；提交时过滤 API 字段，避免编辑原档案顺带改变授权。
- 配置与凭据统一在仓库行的“API 接入”维护。外部仓库编码标为选填，前后端允许留空保存与首次授权。
- 后端允许不带 API 字段创建极风仓库。旧调用方若仍一起提交凭据，保留原校验及事务保护。
- 显式空编码不继承公共配置中的仓库身份。不放宽指定仓库库存查询、同步的身份要求；未配置编码时不得查询其他仓库。旧调用方省略字段时仍保留绑定阶段的兼容解析。
- 无数据库迁移、不改真实凭据、不执行平台调用，不向虚拟机或阿里云发布。

## 验证

前端 33 项组件与交互测试通过，构建通过（2130 模块）。后端复现发现并修正新增档案强制 API 凭据的旧校验；独立边界测试 4 passed，覆盖生产/试点允许空编码、同步仍受限、禁止继承其他仓库查询。

用户登录后只读核对 THCS：编辑弹窗只含档案字段；API 接入显示配置选择、Email、空的 Token 输入和“服务商外部仓库编码（选填）”。未点击保存、授权、检查或同步，未变更现有记录。此次为实际会话结构核对，不代表完整视口/缩放或真实平台验收。

后端最终回归 43 passed（130.59 秒）：可选外部身份、仓库凭据、绑定生命周期及凭据幂等。仅重启本地 8002 后端加载变更，3001 入口不变；无数据库迁移。
