## 生产安全边界

1. 本候选版不提交任何平台密钥、令牌或生产环境文件；页面只处理凭据引用和脱敏信息。
2. 生产写能力默认关闭；页面能力矩阵不得绕过后端准入、权限、审批和运行门禁。
3. 当前虚拟机的 Shopee 配置可继续按既有只读控制链做生产验收；Lazada、TikTok Shop 仍需分别完成真实凭据、回调、合同校验和负责人审批，不能因菜单就绪自动视为准入。
4. 商品映射必须先登记建议，再由有权人员确认；不允许从未映射状态直接变为已确认。
5. 审计集合接口限定当前租户与用户数据范围，支持分页和严格过滤，返回内容使用现有脱敏序列化合同。
