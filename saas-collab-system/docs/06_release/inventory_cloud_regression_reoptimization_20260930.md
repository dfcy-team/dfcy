## 修正

- 两页共用按授权范围、站点、仓库、来源 SKU 选取最新记录的非相关窗口子查询；避免每个外层历史记录再执行相关 `LIMIT 1` 查询。
- 工作台概况和无清单筛选时的待核查总数直接从仓库分组统计计算，减少两次重复选择与汇总；保留筛选后精确计数、50 条清单上限与全部授权范围概况。
- 库存分析沿用相同的最新/日末快照选择；日期范围先应用，SKU、风险和虚拟商品过滤后应用，保留全量排序、分页及稀疏历史的 14 个有效趋势日。
- 库存分析使用与工作台一致的 30 秒客户端上限。延长上限不作为提速验收依据。
- 无新增数据库迁移，复用 V196 的索引。
