## 隔离执行方式

执行器位于工作区临时目录：`C:/Users/Administrator/Desktop/开发/.codex-tmp/run-isolated-acceptance.py`。

它在导入 Django 前固定 `DB_ENGINE=django.db.backends.sqlite3`、`DB_NAME=:memory:`，清空数据库主机/账号字段，并再次断言数据库引擎和名称；设置 mock 模式、关闭真实采集许可、阻断 socket 连接。只使用测试代码中的假凭据，不读取用户凭据文件。测试进程结束后内存数据消失，不保留为共享业务记录。

上述 114 项执行时没有修改正在运行的本地前后端连接配置、没有切换共享库、没有创建持久 MySQL 验收库，也没有替换用户登录会话。SQLite 通过不代表 MySQL 事务、字段约束和锁行为已经通过。用户后续确认后的隔离环境准备见下文。
