## 异常根因

V2.44.25 的菜单源码 SHA256 与 V2.44.24 相同，但前端生产包实际进入了 Mock 构建分支。V2.44.25 的 `products` 资源只返回本地 Mock 数据，不包含真实 `/api/internal/products/` 请求；Mock 身份和权限数据会改变菜单可见项及多个页面的展示，因此该版本已回退。

V2.44.26 使用以下显式构建参数重新生成生产包：

- `VITE_USE_MOCK=false`
- `VITE_API_BASE_URL=''`

新 `products` 资源已确认包含真实产品 API，且不含 Mock fallback 运行分支。

## 本版授权范围

仅调整“基础档案”下的两个页面及其专用 API，不修改菜单、导航布局、商品主数据或其他业务页面。

### 商品明细数据

- 操作列支持编辑 SKU 安全字段。
- 支持按旧 SPU 或新 SPU 精确批量修改。
- 未选择记录时作用于该 SPU 的全部跨页匹配记录；选择记录后只修改选中项。
- 类目修改校验当前租户、启用状态和可编码层级。
- 空字段不覆盖原值，重复提交返回无变化统计。

### 平台商品明细数据

- 增加分类目录树和服务端分类筛选。
- 操作列支持编辑平台商品信息及安全的 SKU 映射。
- 支持按旧 SPU 或新 SPU 批量预览、二次确认和修改。
- 旧 SPU 通过当前租户的旧商品关系解析，不直接把旧 SKU 当作旧 SPU 比较。
- 保留平台、店铺、变体唯一性和租户边界校验。
