# SaaS 协同系统 V2.44.19 平台商品明细大文件导入与分页修复登记

- 登记日期：2026-08-14
- 父版本：V2.44.18
- 发布状态：已登记并部署

本版本只修复平台商品明细数据的大文件重复导入和列表分页；前端、菜单、路由及数据库结构均未调整。

- 根因一：同一文件重复上传时，旧逻辑对约 3.5 万条已有数据全部执行全字段 `bulk_update`；Django 会构建大量 CASE 表达式，Gunicorn 工作进程内存升高并在 60 秒超时后退出。
- 根因二：平台商品明细列表接口忽略 `page/page_size`，一次返回 36,000 条、约 28 MB 数据，导致导入完成后的页面刷新超时并显示 0 条。
- 导入现在只更新实际发生变化的字段；内容相同的行计入 `unchanged`，不再产生 UPDATE。
- 已有数据查询按平台、店铺和变体 ID 分块，只加载当前导入批次涉及的记录。
- 创建按 1,000 条分块；更新工作集最多 500 条，SQL batch size 为 100，控制内存峰值。
- 平台商品明细列表改为服务端分页，默认每页 20 条、最大 100 条，保留原有搜索和筛选。
- 菜单未修改，菜单 SHA256 仍为 `c4919748b05f596ede323f0dfc86e7d58bcae40abb366b952ffb00889a4b3ab9`。
- 后端镜像：`saas-collab-backend:v2.44.19@sha256:14bd9da9f8fba3ec72a66cd1d46f1fef9f0161e7abe76550744e4139a74c38fa`。
- 前端继续使用：`saas-collab-frontend:v2.44.16`。
- 导入模块 SHA256：`656f3d649dc9c73f24bb126c37cf4cb66e668c94782cc6fbc9277b6ff5d32b05`。
- Listings 视图 SHA256：`70e7c8c697c6448c52db549111fc1f30f541e9aca8521b5a30e6c06bcac93a93`。
