## 核定范围

本版本合并两类已核定增量：API 数据接入生产配置闭环，以及新的菜单信息架构。除下列范围外，不改变页面、接口和权限语义。

### 菜单与路由

1. 保留 V2.44.60 已核定的“业务协同”移除，以及新品市调、采购订单、供应商绩效、价格中心的归属调整。
2. 一级菜单顺序核定为：工作台、基础档案、产品开发、供应链协同、库存管理、全球刊登、销售管理、达人管理、财务中心、经营分析、经营决策、报表中心、流程协同、RPA协同、API数据接入、系统管理、治理与试点。
3. “库存管理”承载库存预警、补货建议；“全球刊登”承载全球刊登工作台、刊登任务、在线商品、平台类目映射、商品属性映射、刊登日志、刊登异常、刊登资料、刊登模板。
4. “系统治理”更名为“系统管理”。
5. API 数据接入保留原有平台档案、平台站点、店铺档案及既有接入入口，新增“生产环境配置”；连接配置使用细粒度配置权限，运行记录显示为“同步运行记录”。
6. 新增 `/integrations/production-settings` 路由；`/integrations/configs` 与 `/integrations/sync-runs` 使用 API 工作台组件，保留配置详情和运行详情路由。非 integrations 路由不变。
7. 销售管理继续保留既有 permissions 与 `showWhenChildAccessible` 规则；内部用户即使没有销售权限仍可见价格中心，外部用户不可见。

### API 与后端

- 新增版本化生产运行配置及系统管理员页面闭环：网络安全门、只读同步开关、出站白名单、OAuth 回调白名单、端点/路径配置、重试策略、凭据托管引用和全球刊登写入保护。
- API 配置、店铺授权、能力矩阵、店铺/商品映射、同步任务/运行、异常及审计工作台使用细粒度权限和后端租户隔离。
- 完善生产只读能力门禁、平台 schema、回调校验、托管服务缓存刷新及刊登生产写入保护；秘密原文不进入配置接口或前端回显。

## 数据库与权限边界

- 数据库迁移：有，新增 `configcenter.0002_production_runtime_definition`，以安全默认值登记 `integrations.production.runtime` 系统配置定义；不修改业务商品、订单或租户数据。
- 回滚说明：应用回退至 V2.44.60 时保留该配置定义，不执行逆向迁移；如需彻底清理，须由数据库管理员在备份后单独执行迁移回退。
- 权限目录：不新增、不替换权限目录；菜单和接口仅复用既有 `config.system.manage`、`config.view`、`integrations.config.view`、`integrations.run_live_readonly` 等权限编码，非 API 菜单权限保持原值。
- 数据库备份：以生产发布流水线实际登记结果为准（若为 `null` 不作已备份声明）；生产配置中的凭据仅保存独立托管引用。

## 变更文件边界

- 前端：API 接入页面、API 调用/Mock、店铺档案接入操作、API 路由和菜单；对应契约测试。
- 后端：`apps.integrations` 生产配置/门禁/视图/序列化器、`apps.configcenter` 配置服务与迁移、刊登生产策略；对应 pytest。
- 文档：本发布登记。
- 未纳入：导航 CSS、业务页面路由（除 integrations 路由组件）、非 API 菜单业务逻辑、额外 Compose 覆盖文件。

## 发布前验证标准

- `git diff --check` 通过，候选分支无未提交文件和来源不明改动。
- 菜单契约覆盖一级顺序、业务协同移除、四项归属、全球刊登九入口、API 入口唯一性、价格中心可见性和权限规则。
- 路由契约覆盖生产配置、接入配置/详情、同步运行/详情及全球刊登九入口；所有菜单路径均有 `routeCapabilities`。
- 前端专项测试、全量测试、生产构建通过；后端 `manage.py check`、`makemigrations --check`、迁移与相关 pytest 通过。
- 发布流程核对菜单/路由/权限文件、数据库迁移、Compose 与镜像来源后，才允许切换生产版本。
