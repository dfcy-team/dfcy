# V2.44.122 Shopee 根地址 OAuth 回调桥接

## 发布目标

- 兼容 Shopee 开放平台只能登记站点 HTTPS 根地址的约束。
- 当根路径同时收到 OAuth `state` 与 `code`/`error` 时，在 Nginx 内部改写到 Shopee 回调处理器并保留全部查询参数。
- 普通首页请求仍返回 SPA；一次性 state、租户、店铺、配置版本和防重放校验继续由后端执行。

## 配置口径

- Shopee 开放平台登记地址、生产运行配置 `platforms.shopee.redirect_uri` 与店铺连接配置必须完全一致。
- 阿里云目标值为 `https://xtsy.dingfengchuangyu.com/`。
- 生产配置仍通过不可变版本、双人审批和审计日志生效；不在发布脚本中写入密钥。

## 变更边界

- 无数据库迁移。
- 无新菜单、路由或角色权限。
- 不启用写同步、全球刊登或其他高风险能力。

## 验收要求

- Nginx 生产与沙箱模板均通过 `nginx -t`。
- Shopee 根地址保存于 OAuth 会话，内部回调可完成，重放仍被拒绝。
- 普通根路径不被改写；缺少合法 state 的请求由后端失败关闭。
- 应用前端构建和受保护 CI 通过后才可发布。
