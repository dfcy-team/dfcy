## 变更范围

1. 组合商品新增导入时，仅在选择已有组合 SPU 时提交 `existing_spu`；新建 SPU 不再传空值，避免 `existing_spu: This field may not be null.`。
2. 对组成 SKU 按普通商品、组合商品、停用和不存在分别反馈；服务端字段错误转换为可读中文，保留 CSV 行号和错误导出。
3. 文件中不存在的目标组合商品仍按新增流程生成新 SPU/SKU 编码，并保存可选的旧 SPU/SKU 编码。

## 验收与边界

- PR #219 必须通过完整 CI，发布前复核其合并提交与主干最新状态。
- 源文件 `91个缺失SKU_组合商品导入_组合62条.csv`（62 行）与 `组合商品补充20260923.csv`（291 行）中，共有 275 个不同组成 SKU 编码；只读租户核对得到 270 个普通 SKU、1 个已存在组合 SKU、4 个不存在编码。
- 当前商品模型禁止组合 SKU 作为组成项，因此 `HYYL391-Big` 对应行不会因本版成功导入。4 个不存在的组成 SKU 也需先补录或修正编码。本版不修改嵌套组合业务规则，不执行用户附件的生产导入。
- 正式发布须通过受保护 PR 与受控工作流，从最终主干 SHA 构建不可变镜像，完成备份、健康及迁移检查；部署后核对运行镜像、双账本和部署标签指向同一 SHA。流水线成功本身不等于两份附件全量导入验收。
