## 变更范围

1. 已有 SKU 的末级分类允许首次设置规格维度，也允许在原有维度末尾追加新维度；旧 SKU 的编码与规格值不改写。

3. `2KG+10LB`、`1KG+5LB`、`2KG+5LB`、`3KG+10LB` 可作为分类配置选项并由现有规则生成 SKU 编码。
