# V2.44.85 飞书达人导入历史状态兼容修正

## 发布边界

- 候选版本：`2.44.85`
- 严格父版本：已部署、已登记的 `2.44.84`
- 父版本提交：`f9860dc1f216b5cdeedbffa7bae854f237b8d609`
- 本版本只扩展已授权的受控飞书导入兼容层；不携带源数据，不执行导入，不修改用户、权限或其他业务域。

## 修正能力

1. 已有送样记录后续进入 `completed`、`cancelled`、`live_creator` 或 `blacklisted` 时，较早的飞书 `pending`/`shipped`/`published` 快照只刷新受管来源事实，不回退现状。
2. 保留状态仍写入幂等 `FulfillmentStatusEvent` 和 `OperationLog`，显式标记 `preserved=true`；重放是完全 no-op，未知状态仍 fail-closed。
3. 新增固定来源的历史 `OutreachTarget` 快照适配器。它在租户锁下核对执行人、租户、任务来源、源任务号和达人身份，只为已审批的飞书/旧来源恢复历史关系。
4. 终态任务不会被重开；互动式 UI/API 的终态任务限制和模型校验保持不变。适配器仅在全部来源与租户不变式通过后使用受控写入，并为创建/恢复动作写入审计日志。
