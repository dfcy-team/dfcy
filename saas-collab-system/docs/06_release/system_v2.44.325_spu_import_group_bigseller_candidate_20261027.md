## 修改内容
- 商品新增 CSV 模板增加可选 SPU 分组标识。同批同标识共用新 SPU；不同批次独立，留空沿用原逻辑。同组分类和属性编码须一致，分组标识不能与新/旧 SPU 编码混用。
- 持久化批次与分组信息，支持分步生成和失败重试；保留租户权限及终止状态校验。生成失败通过保存点回滚，避免残留空 SPU。
- 普通商品 BigSeller 表分类按真实分类树输出一级大类名称。缺失父级时留空；每次导出只构建一次分类索引。
- 自动导出在商品导入及 SKU 生成成功后提示选择系统仓库，将其名称写入表格。取消只跳过表格下载，不影响已保存商品；未选择仓库可留空导出。手动普通商品导出使用同一选择与映射规则。读取仓库沿用现有权限，失败不使用降级模拟数据，不改变库存归属。
