- BD 成员行支持展开菲律宾、马来西亚、泰国国家明细。
- 国家明细展示本币、对应送样、已发货送样、有效订单和本币 GMV。
- 接口返回 `native_gmv`、`gmv_php`、`gmv_myr`、`gmv_thb` 和 `country_breakdown`。
- 本币 GMV 分币种独立累计，不跨币种直接相加；主表 GMV 仍按所选展示币种换算。
- 送样国家优先读取快照站点；当历史站点为飞书选项编码时，回退到店铺主数据国家代码。
