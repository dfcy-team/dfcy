## 功能内容

1. 平台档案、国家信息、店铺档案、仓库档案和供应商档案新增删除操作。
2. 删除前执行二次确认，后端继续使用 `masterdata.manage` 权限并按当前租户、数据范围重新校验目标。
3. 删除前检查所有反向关联；国家信息额外检查当前租户的 `country_code`、`site_code` 文本关联。
4. 仅无关联档案可删除；有关联返回 HTTP 409 并提示停用，不进行级联删除或外键置空。
5. 删除动作在事务内执行并记录操作审计。
6. 分类、属性、颜色的既有删除入口统一关联冲突提示。

## 不增加删除的范围

- 商品主数据、商品明细数据、平台商品明细数据；
- 组合商品、规格配置、基础档案设置。
