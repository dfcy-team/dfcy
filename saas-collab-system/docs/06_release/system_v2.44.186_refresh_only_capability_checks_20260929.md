## 功能增量与菜单

1. API数据接入 / 能力矩阵：增加店铺、仓库切换，集中发起显式只读检查。店铺按选中商城授权和具体资源检查，读取关闭或资源未支持时不得调用外部接口。仓库展示实际共享配置读取审批开关、检查状态和令牌期限；修改审批仍走连接配置。
2. 基础档案 / 店铺档案、仓库档案：API接入弹窗检查入口统一导航至能力矩阵；手动刷新只换令牌并保存，不再隐式重新验证。显示令牌期限，店铺刷新时间与首次授权时间区分。
3. API数据接入 / 集成审计：automatic_refresh 的 success 仅表示刷新与安全保存完成，审计明确 readonly_validation_performed=false，不能据此认定真实业务接口可用。
4. 自动调度：到期前刷新不再请求业务只读接口；保留审批、权限、运行互斥、一次性去重和凭据保管门禁。历史验证失败由人工刷新或显式检查处理；不自动恢复已暂停任务。

不新增菜单或路由，现有 108 菜单、142 路由分布保持一致。平台商品、订单、退货退款、财务流水和极风库存使用现有检查接口；广告/报表等未实现资源明确标记尚未接入检查，不冒充商城检查结果。
