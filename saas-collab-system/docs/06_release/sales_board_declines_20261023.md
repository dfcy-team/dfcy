# 大屏下降排行与原因证据

在国家／ROI候选653f0942之上实施。本地候选，未部署。

## 行为
默认保留原销售贡献与五维排行，具有商品销售权限时可切换下降异常。模块懒加载，只有打开且日期已结束、币种已选时请求；不加入原60秒大屏轮询。改变国家、店铺、日期、币种或排序会取消旧请求，旧结果清除。

排行按店铺+平台商品链接+币种，从完整权限交集内SQL聚合、排序后取前10。金额口径为非取消商品行金额，前一等长期间比较；后端还须核验相关店铺当地日期均已结束，不能仅凭北京时间过零点认定。没有完整两期观测或前期非正值的链接不计算降幅；只给基于已入库数据的下降事实，不声称采集完整。

点击“查看依据”在大屏展示同一范围的本期、前期、降幅和缺失证据。只有昨日单日下降严格超过30%才显示SOP触发说明；不声称推断出流量、广告或缺货原因。

## 工作台对齐边界
采用工作台候选的日期、region、currency、店铺、平台与诊断数据字段。工作台候选6e2f30fd尚未合入本基线，且仅消费日期跳转参数，故本批不生成会丢失店铺/国家的跳转。完整跨页面商品定位及共享诊断服务抽取在工作台候选整合后实施。

## 验证
前端19项定向测试通过（含默认不加载、轮询不带下降请求、迟到响应丢弃）。生产构建、菜单快照、前端权限引用清单检查通过。后端隔离测试7项通过（158.57秒），覆盖权限交集、跨租户、全量排行、缺失与零基准、30%阈值、店铺时区和极端日期。独立审阅发现的时区问题及复核发现的日期上界问题均已修复，根代理复核通过；git diff --check通过。

## 未包含
历史人民币折算、流量/转化诊断、历史库存原因判定、飞书发送和正式发布均不在本批实施范围。

## 独立审阅
发现跨时区日期边界：上海已进入下一日时，美国店铺仍可能处于观察日。应按店铺当地已结束日进行后端校验，诊断昨日也按该店铺时区判定。前端仅作为预筛，后端为最终约束。原有权限交集、全量SQL后取TOP10和异步响应隔离已通过静态审阅。

极端未来日期在构造查询窗口前返回400，避免日期溢出造成500。百分比排序在SQL中使用浮点比率以兼容SQLite及MySQL；返回金额与变化比例仍以Decimal计算。极接近比例可受浮点精度影响，当前按店铺与商品ID稳定打破并列。

生产MySQL执行计划、代表性数据量接口耗时与真实普通账号业务验收尚未完成；隔离SQLite测试及构建结果不等同于生产性能验收。
