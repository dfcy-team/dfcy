# V2.44.201 报表与 BI 调整发布登记

版本基线为虚拟机 V2.44.200（`823f0fde2f4293a8cbd20db33b0e4a4a8e855cac`）。用户已授权登记以上报表调整版本并部署虚拟机。此文件登记候选发布内容；实际部署时间、合并 SHA、CI 工作流、镜像摘要、备份和验收结果以部署后的双版本账本及发布回执为准。

## 内容及菜单归属

销售管理提供订单、SKU 销售和退款分析；库存管理提供快照数量与缺货风险分析；财务中心提供平台流水、费用分类、匹配情况及库存估值和成本覆盖。经营分析提供跨模块综合模板及 BI 分析入口。报表中心统一管理目录、个人视图、共享视图、字段分析和组合看板。

保留现有路由和权限目录（108 个菜单、142 个路由）；侧栏隐藏尚无广告数据支撑的经营分析广告总览、广告效果、财务广告对账三项入口。各业务模块入口预选所属模块模板和数据集，库存估值归财务中心。

BI 支持拖动字段组合行、列、指标和筛选，切换表格、图表及多维透视；组合看板支持 1–8 个组件、拖入、重排、调整尺寸、联动筛选、个人或共享保存，以及按当前查询配置导出组件 CSV。穿透携带实际业务维度进入已有明细页；缺成本、未关联和不同币种分别呈现。

## 数据与安全边界

六个受控数据集为 sales、sales_skus、refunds、inventory、finance、inventory_value。聚合由数据库完成，常规查询最多 500 个分组，导出最多 10,000 行；60 秒缓存绑定租户、用户、当前权限范围和查询。调整展示布局复用聚合结果，看板最多三个请求并发，并取消过期查询。

查询、目录、保存和导出均检查报表权限、报表类型范围和来源业务权限；共享仅共享配置，每次读取重新校验当前查看者权限。导出文件保存来源授权范围，下载时再次校验，具备文件哈希、有效期及 CSV 公式处理。

当前数据不构成完整利润、回款、总账、批次库龄、收发存或补货预测；待接入能力在页面注明。库存按截止时点最新快照，成本按仓库和有效时点已确认版本，金额保持原币种，不将缺成本补为零。

用户补充授权：虚拟机部署验收登记完成后，交由“阿里云正式系统发布通道”审核，并按云端实际基线累计增量发布。已登记云端基线为 V2.44.198，因此审核清单应包括 199–201 的同步运行时、商品范围和报表改动；不执行待审的云端角色/成员方案或重置同步任务。失败时使用现有控制流程恢复前一应用镜像；本次新增结构保持兼容，不自动反向执行迁移。
