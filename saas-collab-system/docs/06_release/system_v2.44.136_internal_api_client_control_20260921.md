# V2.44.136 内部系统数据接口配置控制面发布登记

## 版本信息

- 版本：`V2.44.136`
- 登记日期：`2026-09-21`
- 父版本：`V2.44.135` / `v2.44.135-deployed` / `08fa247a971cf3681bb530b3e0c73f074c69141a`
- 发布范围：内部系统数据接口的管理员配置界面、租户级调用方管理后端、权限与审计迁移。
- 数据边界：本版本只提供配置控制面；`/api/internal-readonly/v1/` 业务数据读取端点仍未注册，不允许知识库或内部系统修改业务数据。

## 增量能力

- 管理员可创建、编辑、启停调用方，配置调用类型、资源/字段白名单、CIDR、限流、分页上限和有效期。
- 创建及轮换时仅一次返回明文密钥；数据库只保存不可逆哈希、前缀和指纹。
- 密钥轮换要求 `Idempotency-Key`，重复操作不再次返回明文密钥。
- 后端按租户过滤对象，并使用查看、管理、轮换和审计四项独立权限。
- 配置操作写入不可更新、不可删除的审计记录。

## 数据库迁移

- `integrations.0032_internal_api_client`
- `permissions.0046_register_internal_api_client_permissions`

迁移只新增调用方配置表、审计表和权限目录，不修改现有业务对象。应用回滚时保留新增表与权限记录，禁止手工逆向删除生产数据。
