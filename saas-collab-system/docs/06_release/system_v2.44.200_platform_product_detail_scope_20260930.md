## 功能范围

平台商品明细的数据范围按租户、平台、站点和店铺匹配。旧仓库/供应商范围无法用于该页面时，返回明确的中文整改提示；角色保存会阻止新增不兼容配置。商品映射状态沿用独立权限，并可根据绑定店铺的平台 ID 过滤，防止页面或映射跨越授权范围。详情、创建与修改也使用对应范围校验。

阿里云只读诊断发现共享角色 36 的 `warehouse_ids: [2,3,4]` 被用于平台商品明细，导致目标账号虽有菜单和查看权限，页面仍返回 `403 DATA_SCOPE_INVALID`。业务已确认该角色的 5 位在用成员需要相同的平台商品明细查看权限，范围是 Shopee 全部店铺（含停用）；当前平台 ID 6，27 家店铺、约 20,050 条明细。生产角色拆分方案见 `platform_product_detail_scope_20260930.md`；该方案不是本次虚拟机部署的数据库变更。
