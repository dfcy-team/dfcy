## 功能范围

1. 「商品新增导入」的旧 SPU、旧 SKU 和新 SPU 编码均按场景可选；未填时按商品编码规则生成新 SPU/SKU，填写已有新 SPU 时可追加不同属性 SKU。
2. 重构商品主数据「生成 SKU」：支持有颜色有规格、有颜色无规格、无颜色有规格、无颜色无规格四种模式。
3. SKU 编码按 `{SPU编码}-{ 颜色码 }-{ 规格码 }` 组合，空段自动省略，不产生多余连字符。
4. 颜色×规格矩阵默认全选，允许取消不存在的组合；重新生成只新增缺失项，已有 SKU 不覆盖。
5. SKU 名称按 SPU 名称+颜色+规格自动预填，人工修改后持久化「手动」来源标识。
6. 预览表支持图片 URL/本地上传、重量、长宽高、体积自动换算、人民币采购价，以及单位、原产国、HS 编码和商品描述补充字段。
7. 生成成功后自动下载 `BigSeller商品SKU_<SPU>.xlsx`，只包含本次新建 SKU，用于 BigSeller 导入创建。
