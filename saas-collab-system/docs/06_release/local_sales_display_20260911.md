# 销售管理数据与字段展示优化（本地）

## 范围

销售总览、销售订单、退款退货、门店销售、SKU 销售、销售明细导出、数据同步与质量、价格中心。仅修改前端展示与测试；沿用现有后台组件、菜单及权限。不改变统计计算、同步规则、授权或业务记录。

## 调整

- 字段契约统一金额两位小数、数量千分位、比率百分数、UTC 时间；缺失显示“—”，零和负数保留。编号不转数值、不丢前导零。订单详情保留原始金额便于核对。
- 业务状态中文化，保留平台原始状态及未知枚举。门店名称与编码分别展示；SKU 表补充门店、平台和站点；内部 SKU 缺失明确显示“未关联”。
- 列表、只读详情使用相同格式。所有列表提供明确详情入口；订单商品行与售后商品行按实际字段展示，不混用金额字段。空列表仍保留表头。
- 修正趋势对真实接口按币种对象的解析，按币种独立展示最近七个数据日期；零基线、负值和缺失日期不再被绘制成正数。说明趋势和总览保留取消订单的口径差异，不改变后端统计。
- 数据质量页展示已有接口返回的同步来源、最近运行与成功时间、获取条数、错误摘要；不展示凭据和同步游标。无质量问题不再等同同步成功，零检查记录不显示满分。
- 未返回异常明细时不再显示“未发现异常”。请求失败清除旧指标，忽略过期响应；详情防止旧请求覆盖新选中订单。
- 价格中心明确“待接入”，无真实价格接口，不新增请求或启用价格写操作；模拟模式单独标识。

## 验证

- 新增字段格式与页面运行测试，结合既有销售、菜单、权限边界测试共 38 项通过。
- `npm run build` 成功；菜单权限快照校验通过。构建仅有第三方依赖 PURE 注释警告。
- 使用正常登录的本地会话逐页只读检查八个页面，并打开订单详情；总览实际金额、订单状态、商品行、SKU 来源与同步来源可正常展示。
- 未触发同步、授权、导出申请或价格写入；未部署远端。

## 限制与观察

- 当前退款与导出列表为空，真实空状态已验证；有记录状态用合成数据测试。
- 价格中心后端仍未实现，本轮只改善待接入展示。
- 检查时 TikTok 订单及退款同步最近运行状态为失败、错误码 `MAX_RETRY_EXCEEDED`，保留真实失败状态，本轮未更改同步逻辑。
- 平台订单 SKU 与内部 SKU 尚未关联的记录按事实显示“未关联”，不套用库存 SKU 关联结果。
