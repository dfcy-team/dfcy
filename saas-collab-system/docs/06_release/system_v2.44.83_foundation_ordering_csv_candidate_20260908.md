## 基线核对与实际增量

V2.44.81 已将商品主档按 `-updated_at, -id` 排序，并将商品明细中的旧品桥接行和独立 SKU 行先合并按实际变更时间排序、再分页；已映射 SKU 变更会推动对应旧品行置顶。这些已发布能力不重复进入本候选。

本候选只包含两类净新增：

1. 平台商品明细列表在租户、店铺、自定义数据范围、映射及搜索过滤完成后，在分页前按 `-updated_at, -id` 稳定排序。回归用例覆盖排序、同时间戳 ID 倒序、先排序后分页、更新后置顶、自定义店铺范围和跨租户隔离。
2. 商品图片批量 CSV 导入改为异步分片解析：每 32 KiB 让出主线程并报告进度，每 250 行校验后让出，预览固定 50 行分页，后端请求维持每批 5 行且每批后让出。支持 BOM、CRLF、引号内逗号/换行、双引号转义和 GB18030 回退解码；拒绝未闭合引号与超过 10 MB 的文件。读取期间显示明确状态并禁用提交。
