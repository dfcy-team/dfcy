## 补齐内容

1. 商品主数据列表与分类、颜色、属性字典并行请求，解除列表对字典串行加载的等待。
2. 商品明细字典缓存并合并并发请求，查询和翻页复用已成功加载的字典。设置保存使缓存失效；加载失败允许重试，避免永久缓存失败状态。
3. 商品明细后端按数据库计数和分页切片，仅序列化当前页。保留旧明细优先、独立 SKU 随后、链接去重、租户与可见范围过滤及超界页返回最后一页的原契约。
4. 未选可选规格的内部规范值仍为 `0`，但不拼入规格展示与新 SKU 编码；全部未选时不追加末尾分隔符。例如 `101011001-aqua`，部分选中时仅拼选中规格。保留字典配置值 `90X200CM`、`2PCS-1` 的合法性及非法值拒绝。
5. 已有旧含 `0` 编码仅用于兼容查找，不重写；批量重试跳过旧组合，单条自动生成遇到旧组合返回校验冲突。显式旧商品导入仍保留既有独立源记录分配逻辑。

- 前端最终全量复核：82 个文件 / 488 项测试通过；生产模式构建通过，权限快照 100 菜单 / 133 路由不变。静态生产基线门禁通过。

- 环境：本地 Vite `127.0.0.1:5190`，Playwright + Edge，桌面 1700×1000、手机 390×844。Browser plugin not available；采用已有 Playwright，无新增依赖。

- V2.44.79 主列表等字典响应后才请求；候选版本在字典响应之前请求列表。

- 注入首次字典失败后，页面展示具体错误；点击查询触发一次 4 请求重试并恢复字典，之后翻页不再增加字典请求。字典缓存按用户/租户作用域隔离，分类/属性/颜色/规格设置成功写入后失效。
- 页地址、标题、非空内容、无框架错误遮罩、控制台、列序与分页颜色通过。
- 同一 SPA 保存颜色返回、SKU 详细失败提示及保留选择后成功重试通过；手机仅布局冒烟，既有窄表格固定列占位问题不在本轮扩大修复。
- 业务交互均使用隔离测试响应；生产不生成测试 SKU。
