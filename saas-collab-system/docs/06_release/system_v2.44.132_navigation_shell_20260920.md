## 变更范围

1. 桌面端左侧导航固定在视口，品牌区保持固定，超出可视高度的菜单在导航内部独立滚动。
2. 右侧顶部新增已打开页面页签，支持点击切换和原生拖动排序。
3. “工作台”作为固定页签；其他页签可手动关闭，关闭当前页签后自动切换到相邻页签。
4. 页签列表保存在当前浏览器会话中，路由切换、布局重新挂载或页面刷新后仍可恢复；手动关闭后同步移除。
5. 主内容区右下角增加位置感知的“返回顶部”和“直达底部”按钮，仅在当前位置可执行对应操作时显示。
6. 移动端保留抽屉导航，并调整顶部页签与用户操作区，避免窄屏下互相挤压。
