# V2.44.70 权限用户管理与治理试点增量发布登记

- 日期：2026-09-06；目标：应用虚拟机 `192.168.174.131`，用户功能验收以租户 1 为准。
- 本批用户授权：将“权限用户管理”和“治理与试点模块”对话增量进行版本登记并部署虚拟机。
- 正式父基线：V2.44.69，`98487f629e0153ee408fc3b559571b2ab8acda45`。
- 权限用户管理增量已经作为 V2.44.69 正式基线组成部分发布，本版不重复套用、不改其后端模型、迁移、权限目录或授权数据。
- 本版新增来源：治理与试点候选提交 `4abb84e9a507fa4f5d7f475db67cb5c9ce1eee50`；其父提交的治理执行能力已由 V2.44.59 纳入当前主线，本版只提取尚未发布的前端工作台收敛增量。

## 核定增量

1. “治理与试点”一级菜单位置保持不变，二级入口由原 12 个分散页面收敛为 4 个中心：治理中心、验证中心、发布中心、运维控制台。
2. 新增 `/governance` 与 `/pilot/validation` 聚合路由；`/pilot/releases` 同时承载发布与恢复视图；`/pilot/control-room` 聚合拓扑、容量和运行状态。
3. 原 API 合同、助手治理、准入、拓扑、恢复、发布、容量、安全评审、受控验证、性能验证及准入决策详情路由全部保留，作为聚合中心的明细入口。
4. 聚合中心继续使用既有治理和试点 permission code，路由按任一相应查看权限准入，页面内再按具体权限裁剪可见功能；不新增后端权限项，不更改既有角色授权。
5. 除“治理与试点”二级菜单及其直接路由外，V2.44.69 的菜单名称、顺序、路由、导航样式、模块开关、权限用户管理页面与权限目录保持不变。

## 数据库、发布与回退边界

- 本版为前端增量，不新增数据库迁移，不修改后端模型和权限目录，不执行写入式权限同步。
- 发布前后比较所有租户的 Permission、Role.permissions、UserRole、DataScope 及角色稳定标识摘要，必须完全一致。
- 生产构建必须使用 `VITE_USE_MOCK=false`；通过受控 CI 从正式合并 SHA 构建不可变镜像，发布前创建数据库备份并保留 V2.44.69 镜像。
- 若聚合工作台出现权限或导航回归，优先回退前端镜像至 V2.44.69；不回滚或覆盖业务数据库。

## 验证要求

- 前端专项测试、全量测试、生产构建和依赖审计通过。
- 核对一级菜单顺序不变、非治理菜单树不变、治理二级菜单精确为 4 项、旧详情路由仍存在、聚合路由权限契约正确。
- CI 门禁、部署流水线、VM 双账本、运行镜像、首页与健康接口、租户 1 治理只读接口及浏览器桌面/移动端验收均通过后，才登记为已部署版本。
