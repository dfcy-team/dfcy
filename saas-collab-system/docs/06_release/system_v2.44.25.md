## 商品明细数据

- 操作列新增“编辑”，可安全修改 SKU 商品名称、类目、采购价格和商品状态。
- 新 SKU 编码及已有新旧编码关联不可通过普通编辑直接改写。
- 增加按旧 SPU 或新 SPU 精确匹配的批量修改。
- 未勾选记录时修改该 SPU 的全部跨页匹配记录；勾选后仅修改选中记录。
- 空字段不覆盖原值，重复提交返回“无变化”，并返回匹配、更新、无变化及错误数量。
- 类目修改仅接受当前租户启用且可用于编码的有效分类；已生成 SKU 的类目不可批量改写。

## 平台商品明细数据

- 左侧新增分类目录树，分类筛选由服务端根据关联内部 SKU/SPU 执行，保留分页能力。
- 操作列新增“编辑”，支持修改标题、变体、平台商品/变体标识、平台 SKU、销售状态、负责人、组长及安全的 SKU 映射。
- 增加按旧 SPU 或新 SPU 精确匹配的批量修改及预览、二次确认、结果状态。
- 旧 SPU 会先在当前租户的旧商品关系中解析为旧 SKU 集合，可匹配尚未关联内部 SKU 的平台记录。
- 平台/店铺变体唯一性、SKU 存在性及租户边界继续由后端校验。
