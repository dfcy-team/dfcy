# V2.44.76 组织、角色复制与基础档案修复

## 版本关系

- 版本：V2.44.76
- 父版本：V2.44.75
- 范围：部门名称按输入值显示、角色复制为自定义角色、基础档案商品字典闭环修复
- 数据库迁移：无

## 增量内容

### 组织架构

- 部门树、列表和编辑界面直接显示后端保存的部门名称。
- 移除按关键字将部门名称自动替换为 Shopee/TikTok 展示名称的逻辑，确保输入内容与显示内容一致。

### 角色与权限

- 角色列表新增“复制”操作，可将内置角色或自定义角色复制为当前租户的自定义角色。
- 复制时继承源角色的权限和数据范围，允许用户重新填写名称、编码、描述并继续配置权限。
- 后端使用事务、租户隔离、委派边界、编码重名校验和审计日志保护复制操作。

### 基础档案

- 恢复分类设置树状显示、筛选、新增、编辑和移动；移动只调整目录归属，不改已有 SPU/SKU 编码。
- 恢复属性设置与颜色设置的数据展示、维护和启停操作。
- 恢复规格设置，修正请求方法与请求体字段，支持 L3 分类及没有 L3 下级的 L2 分类维护规格维度和选项值。
- 商品主数据创建商品时将“季节编码”改为“属性编码”，使用属性字典中的启用编码；保留兼容字段和默认编码 0。
- 属性编码支持 0–9；SPU 流水号生成前按已存在编码校正，避免分类移动或历史导入导致重码。

### 发布门禁兼容

- 菜单权限快照比较在 Windows 下统一换行符后再核对，避免 CRLF/LF 差异被误判为菜单内容漂移。
- 此调整不改变菜单、路由或权限快照内容。

## 基线保护

- 未新增、删除或重排菜单。
- 未修改前端路由及深色导航样式。
- 未修改权限目录、角色权限定义或菜单权限快照内容。
- 未修改数据库模型、迁移和生产配置。
- 仍以 V2.44.75 的 100 项菜单权限、133 项路由能力为发布基线。
