# 本地模拟同步入口修复（2026-09-11）

## 问题与修正

- 停用任务仍显示可点击的模拟运行按钮，后端返回英文错误。
- 模拟接口原先按配置选择适配器，不能保证只运行 Mock。
- 页面现在根据任务状态和配置环境禁用按钮并提供中文原因，提交处理同时校验，避免重复点击。
- 后端保留租户及操作权限校验；停用任务返回中文提示。模拟入口仅接受未绑定店铺/仓库授权的 `mock` 环境、`mock_record` 资源任务，并显式使用 `MockPlatformAdapter`。
- 真实业务任务不能借模拟入口推进游标或检查点。没有增加真实同步入口、自动启用或调度行为。

## 验证

- 修正前：新增后端 7 项隔离测试失败；前端新增 6 项交互测试失败。
- 修正后：后端隔离、阶段 2 同步框架、能力门禁共 34 项通过；前端任务交互、权限、缺失任务预览、同步健康契约共 23 项通过。
- 后端测试使用独立内存数据库并禁止外部网络；验证拒绝请求不生成运行记录、游标或检查点，合法 Mock 请求保留幂等性。
- Django 系统检查无错误。仅重启本地 8002 后端，3001 页面已刷新核验：7 个任务仍停用，7 个模拟运行按钮禁用并显示中文原因。
- 未调用真实平台、未启用真实任务、未部署到虚拟机或阿里云。
