## 修复内容

1. 角色高级配置的每个权限分组显示“已选 X / 总数”，勾选或取消后实时更新。
2. 保存失败时解析并显示后端字段校验详情，例如业务范围、仓库或权限编码错误，不再只显示通用的“提交内容校验失败”。
3. 业务范围选项请求增加并发序列保护，旧租户请求不能覆盖当前租户选项。
4. 范围选项加载或失败时禁止提交自定义范围，并提供显式重试，避免用旧选项或未完整选项保存。

本候选不修改角色 36 或其他角色的现有权限和数据范围，不新增权限码，不放宽租户隔离或服务端鉴权。
