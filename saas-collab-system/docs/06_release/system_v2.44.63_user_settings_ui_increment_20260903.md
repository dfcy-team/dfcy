# V2.44.63 个人设置界面增量发布说明

## 版本登记

- 版本：V2.44.63
- 父版本：V2.44.62
- 变更类型：个人设置界面与当前用户自助 API 增量
- 数据库迁移：无
- 菜单结构：unchanged（不新增、不删除、不调整菜单顺序）
- 路由目录：unchanged（不修改 `frontend/src/router/menu.js`、`frontend/src/router/index.js`）
- 权限目录：unchanged（不修改权限 catalog 或 migrations）
- 角色与权限基线：完整保留 V2.44.62 已核定的角色改造、菜单授权与数据权限能力，本版未覆盖或重排。

## 功能范围

- 顶部账号区新增“个人设置”入口，支持查看和修改当前登录用户的姓名、邮箱、手机号码。
- 新增当前用户个人资料读取/修改接口；服务端始终以当前认证用户为目标，不接受用户 ID 参数。
- 新增当前用户修改密码接口：校验当前密码、确认密码，密码长度至少 12 位并执行 Django 密码强度校验；成功后前端清理会话并要求重新登录。
- 个人资料和密码变更写入操作审计日志；审计记录不保存密码或其他凭据内容。
- Mock 模式提供等价的个人设置交互数据，便于页面测试。
- 角色改造按 V2.44.62 基线延续：个人设置仅展示当前用户已分配角色，不改变角色、菜单、路由和权限配置。

## 变更文件

- 前端：`auth.js`、`mock/auth.js`、`UserSettingsDrawer.vue`、`MainLayout.vue` 及相关测试。
- 后端：账户内部 URL、序列化器、视图及认证 API 测试。
