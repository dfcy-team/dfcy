# SaaS 协同系统 V2.44.23 商品明细数据升级登记

- 登记日期：2026-08-14
- 父版本：V2.44.22
- 发布状态：已登记，待部署

本版本只调整“基础档案 > 商品明细数据”页面及对应产品接口，不修改菜单结构、全局路由、权限目录或数据库字段。

## 功能变更

- 商品明细页面新增左侧分类目录树；选择分类后由服务端筛选该分类及其子分类下的 SKU。
- 新增服务端分页、全局搜索和“在售/下架”状态筛选。
- 商品名称拆分为“SKU商品名称”和“SPU商品名称”，SKU 明细不再复用 SPU 名称。
- 操作列提供“查看”“调整并生成”“启用/停用”；写操作继续受 `products.master.manage` 权限控制。
- SKU 状态统一为：启用显示“在售”，停用显示“下架”；旧商品的“待调整/已生成/生成失败”作为独立转换状态展示。
- 旧商品导入按租户与旧 SKU 编码幂等识别：新记录新增，字段变化才更新，无变化不写入，异常行跳过并返回行号与原因。
- 导入过程显示读取文件、校验数据、增量更新和完成阶段，并展示耗时及新增、更新、无变化、跳过、异常统计。
- 已生成 SKU 的类目、属性码、颜色和规格不能被导入文件覆盖，避免破坏旧商品与新编码关系。
- 页面说明改为：“维护旧 SKU 与新 SPU/SKU 的对应关系。导入后可逐条补充信息，再生成新编码。”

## 接口与数据

- 新增 `GET /api/internal/products/details/`，支持 `search`、`category_id`、`sku_status`、`page`、`page_size`。
- 复用现有 `ProductSKU.product_name` 与 `ProductSKU.is_active` 字段，无需数据库迁移。
- 旧商品导入返回 `created`、`updated`、`unchanged`、`skipped`、`errors` 和 `duration_ms`。
