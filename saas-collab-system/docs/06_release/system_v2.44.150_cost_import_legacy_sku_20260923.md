## 变更范围

1. 商品成本导入模板新增可选“旧SKU编码”列；“SKU编码”和“旧SKU编码”每行至少填写一项。

4. 既有按当前 SKU 导入的 CSV/XLSX 文件保持兼容，历史成本版本仍按生效期间追加，不直接覆盖。
