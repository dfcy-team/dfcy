## 发布范围

本版本是在 V2.44.61 上的最小增量合并，包含三部分：

1. 界面用户化修订：登录页、应用标题及主布局文案调整，保留既有深色侧栏样式。
2. 基础档案/API-WMS 配置补充：平台档案展示仓储业务分类、服务商及连接器识别信息；管理资源页支持动态选项分组、字段说明和无障碍描述。
3. 角色权限改造：将权限目录拆分为菜单、操作、字段三类，并补充系统管理中的租户管理入口、租户管理 API、角色/用户管理闭环、数据范围和敏感字段脱敏边界。

全球刊登、API 数据接入（含生产配置路由）、销售管理可见性及既有 17 项一级菜单顺序均以 V2.44.61 为准。本增量只在“系统管理”下新增租户管理入口，不替换既有 `menu.js`、路由或导航 CSS。

## 权限与迁移

- `permissions.0038_split_permission_surfaces` 依赖生产已有的 `0037_seed_pilot_execution_permissions`，新增 `permission_type`/`metadata`，并为系统菜单和字段目录做兼容回填。
- `permissions.0039_register_warehouse_connector_role_permissions` 依赖 `0038`，修复并登记基础档案、API/WMS 配置及凭据轮换权限；仅向有效的租户管理员角色补授，不改变普通角色既有授权。原来源中的 `0037_register_warehouse_connector_role_permissions` 不纳入迁移图。
- 后端 action 权限仍独立校验，菜单权限只控制入口可见性，字段权限不绕过后端脱敏；租户查询和角色/用户变更保持当前租户隔离。

## 回滚要求
