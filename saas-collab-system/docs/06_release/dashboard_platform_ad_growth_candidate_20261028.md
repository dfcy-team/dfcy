# 工作台平台切换与每日广告花费环比

2026-10-28 本地开发候选；基于店铺切换提交 `1c063e8b9a2cee551b0e17b15fb2f3581f10d3b4`，尚未部署。

平台选项取自实际销售数据权限与店铺档案人员交集。平台切换清空原店铺选择，并更新可选店铺及图表。无销售的可管理店铺仍可选择，非法或重复平台 ID 返回 400，越权或平台与店铺不匹配返回 403。

每日卡片及最新一天增加广告花费环比。广告还需经营分析权限及其数据范围；TikTok 另受广告账户映射的集成查看范围限制。销售权限不能扩大广告权限。月初使用上月最后一天作为基准；只有明确记录的零才参与计算，缺数显示暂无数据。币种分开统计，广告记录币种和时区必须与所选店铺一致。汇总中任何对应币种店铺缺少有效日数据，整日广告花费留空，避免部分覆盖导致假环比。

Shopee 采用店铺级广告日报花费；重复店铺日币种记录不做不明含义的累加。TikTok 采用已存 BASIC/AUCTION_CAMPAIGN 竞价广告花费，不含 GMVMax / 全部广告口径。数据仍可能因同步和归因回补变化。

平台和店铺选项只查主数据；订单及广告限定本月和上月末一天。平台/店铺切换一次请求返回所有指标，币种切换不请求后端，异步旧响应不能覆盖新筛选。不增加数据库迁移或跨请求权限缓存。
