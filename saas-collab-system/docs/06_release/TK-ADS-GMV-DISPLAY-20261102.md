## 原因和口径

用户截图展示 BASIC 竞价日消耗为0，而 TikTok 展示 GMV Max。两者是不同报表，不能以 GMV Max 覆盖 BASIC 事实。本次未验证 BASIC 零值的完整采集来源，因此不把零值解释为全部广告真实零消耗。

对照 dfcy `platforms/tiktok/marketing/report_client.py`：GMV Max 使用 cost、orders、cost_per_order、gross_revenue、roi，并按真实 store_id 过滤；创意、直播与计划报表粒度不同，不能相加制造总消耗。本次复用 SaaS 已部署正式命令，不复制 dfcy 业务逻辑，不使用其中的 Token 或中转。
