## 同单位多单付款（本次补齐）
- 费用与结算 → 按往来单位对账新增批量申请；驾驶舱单位排行支持“去付款”。
- 同供应商多张发货单、同货运公司多张国内运费/发运批次/入库清关费用，可选2—20项、逐项填写本次付款金额，统一使用所属收款账户。不同对公对私性质分开申请，采购定金沿用原单流程。
- 单次审批，沿用飞书通知进入系统审批；审批后上传最多5份转账凭证，财务确认时原子化写入各来源付款流水并关联凭证。实际转账仍由用户办理。
- 来源流水、付款申请及审批均可穿透批量付款详情；批次子付款不可独立冲销，整组冲销保留原流水。
- 提交和确认均在租户事务锁内复核来源余额、项目余额和其他有效申请占用；限制重复明细、跨单位和账户性质不符；支持幂等重试。任一行入账失败整组回滚。
- 批次和审批权限要求全部来源可见；数据库过滤后分页。候选按来源单据分页，仅计算本页金额；历史列表不展开逐单付款流水。
- 数据库迁移新增 supply_chain.0056_supply_payment_batches，不修改原有单笔付款关系。
