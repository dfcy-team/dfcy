## 修复内容

- 根部门在编辑时将空的上级部门值规范为 `null`，避免 PATCH 请求因空字符串返回 HTTP 400。
- 后端部门序列化兼容历史页面提交的空字符串，并统一按根部门处理。
- 组织架构新增、编辑、启停、删除失败时优先展示字段校验原因，不再仅显示通用 `error message`。
