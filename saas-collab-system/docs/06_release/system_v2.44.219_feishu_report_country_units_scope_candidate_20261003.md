## 数据库核对与修正

2026-10-03 09:14（北京时间）的阿里云数据库只读快照包含历史订单 606,611 单，最新订单业务日期为 2026-09-30；2026-10-02 日报日期内已入库订单为 0 单。更新旧订单的时间不能作为新业务日期。候选在销售及 SKU 销量报表本期无记录时，同时显示统计日期和该收件人权限内数据库最新可用业务日期，不自动改成其他日期，也不把未入库记录解释为实际销量为零。

查询和推送均按收件人实时有效权限读取，显式销售/库存报表资源范围与原业务资源范围取交集。没有显式报表策略时保留合法旧范围行为；无效混合分支不贡献新授权。权限变更和撤销参与缓存校验。

销售、SKU 销量、退款与平台流水按销售/店铺国家分组；库存和库存估值按仓库国家分组。显示国家代码和名称，币种独立分组；未知国家或币种保留指标并明确标记。

订单/售后数量显示“单”，SKU 数量显示“个”，库存/销量显示“件”，流水数量显示“笔”，未关联商品行显示“条”。金额显示原币代码并保留精度。CSV 对应增加国家、单位和最新业务日期信息，保留公式注入防护。
