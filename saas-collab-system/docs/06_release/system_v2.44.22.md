# SaaS 协同系统 V2.44.22 商品主数据操作功能登记

- 登记日期：2026-08-14
- 父版本：V2.44.21
- 发布状态：已登记并部署

本版本仅调整“基础档案 > 商品主数据”页面及前端静态资源缓存策略，不修改菜单结构、路由、后端镜像或数据库结构。

## 页面与功能变更

- 修正“重置”“生命周期”等页面文字，不再显示 `UI-P5`、`tenant`、`data_scope` 和英文连接状态等内部技术信息。
- 商品名称列统一显示为“SPU商品名称”。
- 操作列保留“查看”，并为拥有 `products.master.manage` 权限的用户增加“编辑”和“生成 SKU”。
- “编辑”支持修改 SPU 商品名称和启用的末级类目，通过既有 V2.44.19 后端 PATCH 接口保存。
- “生成 SKU”使用当前 SPU、启用颜色字典及类目规格维度生成；没有可用末级类目时阻止提交并给出明确提示。
- 只读用户不显示编辑和生成入口，也不额外请求颜色字典。
- HTML 和 SPA 路由响应改为禁用缓存；带内容哈希的 `/assets/` 资源使用长期不可变缓存，避免升级后浏览器继续显示旧页面。
