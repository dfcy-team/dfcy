## 验收门槛

- 输入格式错误的 Open ID 时，前端不得允许绑定，后端不得发起飞书请求。
- 有效且应用可访问的 Open ID 可返回用户资料，验证结果可选择并完成绑定。
- 不存在、无权访问或飞书返回标识不一致的 Open ID 必须拒绝绑定。
- 已被同租户其他系统用户绑定的 Open ID 必须提示冲突；原有解绑功能保持可用。
- 后端飞书集成专项测试、前端飞书协同测试与前端生产构建通过。
- 合并后仅可通过既有虚拟机发布通道部署，并在目标虚拟机完成真实飞书 Open ID 查询、绑定和解绑验收。
