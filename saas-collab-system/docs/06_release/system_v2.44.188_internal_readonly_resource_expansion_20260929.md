# V2.44.188 内部系统只读数据块扩展

## 版本与范围

- 原始暂存候选基于 V2.44.185，镜像修订 `f62fee415c92e60a57d0f10195863575473b3779`；该暂存镜像不可直接作为后续版本部署。
- 正式发布父版本为 V2.44.187。发布分支已整合 V2.44.186（含发布测试修复）和 V2.44.187 候选；必须先完成 186、187 的主线合并、虚拟机部署及登记，再从 188 最终主线 SHA 重新构建不可变镜像部署，不能复用基于 185 的暂存镜像。
- 本版本仅增加 14 个显式只读数据块映射，能力目录由 8 个增至 22 个；同步修正管理界面的“基础档案”限定提示。
- 无数据库迁移，不修改调用方配置或密钥，不启用业务写操作，也不执行历史数据回填。
- 数据块、现存记录及待接入原因详见 `docs/01_architecture/internal_readonly_resource_audit_20260929.md`。

## 安全与发布门禁

14 个新增块复用现有 Basic 凭据、来源 CIDR、审批、启用、租户过滤、分页和限流；只返回显式字段投影。发布后，知识库现有批准配置中 10 个新增已勾选块会由“待接入”变为“可读”，其已选可读总数预计由 7 个变为 17 个。发布前必须复核这一实际权限扩张，发布后通过实时能力目录和无凭据拒绝测试验证。

保持各目标环境既有编排、网络、可信代理、现有镜像之外的服务与运行时密钥配置不变；阿里云既有前端固定地址 `172.18.0.6` 和可信代理 `172.18.0.6/32` 不得覆盖为虚拟机配置。先备份目标环境当前编排和数据库，校验镜像构建源、迁移状态与服务健康；如新服务异常，恢复该环境部署前已核验的上一不可变镜像和编排。虚拟机顺序发布时上一版本应为 V2.44.187。不得将目录待接入项宣称为可读取。
