## 核定需求

本版本仅整改“业务协同”菜单的信息架构，不删除业务页面、URL 或路由能力：

1. 取消重复聚合的“业务协同”一级菜单。
2. “新品市调”迁入“产品开发”。
3. “采购订单”和“供应商绩效”迁入“供应链协同”。
4. “价格中心”迁入“销售管理”。
5. “商品主数据”“商品明细数据”“平台商品明细数据”和“刊登资料”沿用原有正确入口，不再从“业务协同”重复显示。
6. 迁移后的子菜单继续沿用原 URL 和权限；价格中心继续仅对内部用户可见，不要求用户额外具备销售管理权限。
