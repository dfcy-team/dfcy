## 变更范围

1. 新增独立 BD 配置页，仅保留默认指标视图、每日归因补偿、送样逾期时长和送样逾期提醒四项配置。
2. 每日归因补偿支持启停；逾期天数限制为 1 至 365 天，默认 20 天；逾期提醒默认关闭并避免重复通知。
3. 建联任务未传负责人时使用当前登录用户；显式选择负责人时校验其负责人资格，并将校验错误返回前端。
4. 送样状态进入已发货时，以实际发货时间重新计算履约截止时间，覆盖人工流转和自动发货路径。
5. BD 绩效查询取消 31 天日期范围限制，长区间由异步任务执行。
6. 报表币种换算改用国家信息中的汇率，按“1 CNY = N 外币”口径换算。
7. 旧组合迁移中如存在组合互相引用，仅跳过会形成嵌套的依赖组合，其他完整匹配组合继续迁移，跳过项进入中文异常文件。
8. 兼容 worksheet 关系使用 `/xl/` 绝对路径的 XLSX，避免完整文件被误判为无可迁移数据。
