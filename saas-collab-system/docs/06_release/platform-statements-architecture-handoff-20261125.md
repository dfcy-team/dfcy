## 数据与权限

- 来源只读；后台写入限于派生缓存、计算任务及无业务数据模板，不自动登记费用、不自动发布有效业务批次。
- 查询范围、明细上下文、当前权限与账务设置版本由服务端校验。跨月自然周扩大日期读取范围，不扩大授权店铺范围。
- 权限清单增加直接查询、查询详情、原始流水列表及详情四个路由，共 12 条 GET/HEAD/OPTIONS 映射；现有非账单端点保留。
- `0019_financesummaryautomationcheck.py` 是账单自动检查诊断表的源码补齐，依赖基线已有 `0018`。不要盲目在生产执行迁移；先核对现有迁移记录与表。此前云端已含部分账单实现，PR 源码差异不等同于服务器待迁移清单。
- 没有新增 commerce 索引迁移；可选旧检查点索引缺失时保留既有回退。后续索引变更需单独评估锁及 IO。
