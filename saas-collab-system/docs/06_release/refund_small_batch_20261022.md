# 退款小批次预设交接（候选实现，2026-10-22）

新建历史补采时，纯 Shopee 退款任务可同时提交 `refund_page_size: 20` 与 `refund_segment_days: 1`。参数必须是整数且只能使用此预设；不能与订单、财务或广告任务混合。请求指纹包含两个选项，创建审计也记录该预设。省略参数的旧请求指纹保持不变，默认仍为每页100条、每段15天。

小批次scope冻结20条分页和一日日期窗口。单次最多生成3100个分段，超出时需缩小日期范围或拆分店铺。此预设不能调整日期范围，避免重规划时静默改回100条/15天；现有普通批次范围调整行为不变。

本能力只允许创建新批次，不恢复或替代现有失败段。生产8号店任务26仍在批次6；该店自身剩余分段虽为failed，批次因其他店仍为running，现有活动批次保护会拒绝同店新批次。不能通过暂停或完成批次6、绕过检查或重用旧段套用20条分页。要安全处理任务26，仍需另一个受审计的失败段替代/恢复入口，并明确保存游标与详情断点的语义。
