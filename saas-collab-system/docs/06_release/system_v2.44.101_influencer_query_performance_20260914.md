# V2.44.101 达人管理取数性能优化

日期：2026-09-14。发布基线：已发布 V2.44.100，`af758477dee483081a8519091202e6d6d11aa503`。

用户已授权本对话通过现有受控发布通道部署原虚拟机。本版本仅包含达人管理四个菜单的取数性能优化，不包含开发工作区中的其他未完成改动。

## 优化内容

- 达人档案：列表保持完整展示字段并排除联系方式、黑名单历史等关系数据；编辑和详情改为单次完整详情请求。
- 建联任务：送样和已发布视频改为数据库计数注解，不再为列表预取全部视频对象；详情按 `outreach_task` 外键精确查询履约记录。
- 送样履约：列表不再返回完整 `video_matches`，只返回注解后的匹配数量；样品项仅加载序列化所需字段。
- BD 绩效：租户汇率一次预载，任务数量按负责人分组聚合，订单最大数据时间在请求内复用。
- 数据库：新增达人、建联、履约和 BD 归因查询索引，迁移编号为 `influencers.0020_influencer_query_efficiency`。

## 发布门禁与回退

发布必须从受保护 `main` 的完整提交 SHA 触发 `Developer A Production Release`，由 CI 构建不可变镜像、执行全量后端测试和前端生产构建，再通过固定 SSH forced-command 入口部署。部署过程先备份、执行迁移，并验证 Redis、后端、Celery、前端、Django production check 和内部健康接口。

若应用健康检查失败，生产控制脚本自动恢复上一受管镜像。数据库索引迁移为可回退结构变更，但普通应用回退不自动逆向迁移；如需移除索引，应在确认查询负载后单独执行受控迁移。

## 验收口径

- 达人档案详情只发起一次聚合详情请求。
- 建联任务详情使用任务外键查询送样履约。
- 履约列表不返回视频明细，详情仍可读取完整明细。
- 多日期、多币种汇率换算只读取一次租户汇率表。
- Django migration、相关后端测试、前端测试和生产构建全部通过。
