# V2.44.126 销售 CNY 换算与订单排序

## 版本登记

- 登记版本：`V2.44.126`
- 目标父版本：`v2.44.125-deployed`
- 发布前必须再次核对虚拟机当前版本、主分支 SHA 和最新 deployed 标签一致。

## 发布目标

- 销售总览、订单、退款、门店和 SKU 报表可显式选择按每日参考汇率换算为 CNY。
- 换算仅发生在已完成租户和数据范围过滤后的响应层，不改写原币事实金额。
- 响应保留原币、原始金额、参考汇率日期和换算公式；缺少汇率时失败封闭。
- 销售订单列表支持受控字段的服务端全量排序、稳定分页和排序重置。
- 补充平台状态 `accepted` 的中文展示。

## 变更边界

- 无数据库迁移；依赖 `V2.44.123` 已登记的国家 CNY 参考汇率。
- 仅接受 `currency_basis=CNY`，不提供任意目标币种或客户端自行计算。
- 排序字段使用服务端白名单，固定以订单编号作为次级排序，不允许租户字段或表达式注入。
- 无新菜单、路由或角色权限；菜单与路由数量保持 `104 / 136`。
- 不修改同步任务、平台凭据、生产配置或原始销售数据。

## 验收要求

- 多币种合并、订单明细嵌套金额、缺失汇率和原币保留测试通过。
- 数值排序、跨页稳定性、租户隔离和非法排序字段测试通过。
- 销售前端筛选、详情换算、排序保持与重置测试通过。
- Django 检查、迁移漂移、前后端测试、生产构建与受保护 CI 全部通过。

## 回滚

- 应用回滚到 `v2.44.125-deployed` 对应镜像。
- 本版本无数据库迁移，回滚不会修改已缓存的国家参考汇率或原始销售事实。
