# 销售报告筛选一致性

范围：销售总览、门店销售，共用的报表组件。仅前端修改，不改业务数据，不执行同步或真实导出。

## 已修正

- 移除图表内“展示币种”和“日/周/月”控件及周/月聚合分支，统一由顶部筛选控制范围，趋势固定按日展示。
- 顶部选全部币种时逐币种展示独立汇总和图表，不跨币种加总、不默默保留第一种。多组图表使用独立可访问性 ID。
- 平台、币种和手动日期均通过查询生效；快捷日期仍是一键查询。草稿筛选变化时显示待查询提示。
- 排序、翻页和导出使用上次成功查询条件，不意外应用尚未提交的筛选。读取失败或加载中不能创建报告导出。
- 默认/重置的过去 30 天与快捷按钮一致，均截至昨天。
- 区间统计视图隐藏无作用的“显示图表”开关。

## 检查边界

保留时间趋势/区间统计（同数据不同呈现）、图例指标开关（仅控制曲线）、SKU 明细搜索（明确仅影响明细）、展示列（仅影响表格）。它们不改变顶部业务筛选，未发现需要重复删除的功能。

后端统计口径没有变更：门店当地筛选日期与来源业务日期/退款 UTC 趋势日期仍可能不同；销售总览汇总与趋势对取消订单的处理差异保留已有说明。本轮不擅自更改业务计算口径，也不代表全站已审查。

## 验证

- 前端 47 项测试通过，包含多币种全部展示、无重复控件、已查询条件隔离、导出参数、日期默认值等。
- 生产构建通过；现有 VueUse PURE 注释警告不影响构建。
- 本地浏览器确认控件已移除；选择平台后原报表保持不变并提示查询，点击查询后结果更新；已重置页面。未执行实际导出。
