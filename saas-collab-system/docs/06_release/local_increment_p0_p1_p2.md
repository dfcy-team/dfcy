## P0：当前空数据的区分

本轮只读复核：订单、订单明细、退款、库存快照、同步任务、同步运行记录均为 0。
因此这些页面的空白首先是无事实数据、无采集任务证据，不能据此新增第二套业务表。

| 业务 | 唯一主系统来源 | 本轮处理 |
| --- | --- | --- |
| 订单销量 | sales_order + sales_order_item.internal_sku | 复用；无 SKU 映射不推测 |
| 退款 | refund_return + refund_return_item | 按币种展示退款明细金额，不抵扣销量、不当作实物入库 |
| 库存与在途 | inventory_snapshot | 同仓库、站点、上游 SKU 取最新记录，再核对内部 SKU；跨仓必须显式选择 |
| 公共配置/授权 | PlatformIntegrationConfig + 店铺/仓库授权 | 不读密文、不复制独立项目 credential_mask 格式 |
| 同步 | SyncJob + SyncRun + 原有能力门禁 | 只增加缺失任务预览，不增加调度器 |

## 已实现入口

1. `GET /api/internal/integrations/sync-jobs/missing-preview/`
   - 仅有 integrations.manage 且在该权限数据范围内可见。
   - 已有任务（含停用任务）不重复列出。
   - 返回 missing / blocked、缺失项，不生成任务、运行、凭据或后台调用。
   - 同步任务页面新增显式预览按钮；错误不保留旧成功结果，无模拟成功回退。
2. `POST /api/internal/replenishment/facts-preview/`
   - 只读 POST；输入 sku_id、store_ids、warehouse_ids，拒绝额外字段。
   - 复用 replenishment.evaluate 权限；范围必须同时允许 SKU、店铺、仓库。
   - UTC 已结束自然日的 30/60/90 天窗口；按创建时间归属，排除取消、待付款、窗口末仍未付款订单。
   - 库存超过 24 小时、缺失快照、映射不全及运行失败分别标记。
   - 输出观察值而非可信建议；不创建补货、预警或生命周期记录。

## P1 未完成项（不能视为验收通过）

- 现有成功 SyncRun 只有计数、检查点和原始证据引用，没有不可变的完整采集窗口证明。
