## 交付内容

沿用“飞书协同 → 报表推送”。报表格式新增 chart（原生图表卡片），保留 card（摘要）和 file（CSV）。默认不变，已有任务不自动切换。支持现有销售、库存、综合经营三种任务，综合按可访问数据源分节。

发送 interactive JSON 2.0，不使用截图、图片或PDF。标题、生成时间、国家、原币、数量单位、指标摘要、原生柱图、范围/刷新信息与“登录查看详细报表”按钮。销售主图为商品金额，库存为在手数量，其他节分别为销量、退款申请金额、流水净额、库存估值。不同币种分图。

图表只消费 build_report(rule, recipient) 的现有权限结果，不另查无限制数据。预览按当前操作者权限，不代表收件人范围，界面明确提示。无数据、无权限、数据源不可用、查询截断均显示状态；缺失保持未知，非有限数字不入图。卡片有面板、国家数、元素和28,000字节限制，省略必须提示。

详情URL只带数据集/日期，不带用户ID、token或免登录凭证。前端按当前用户catalog检查数据集，才应用日期。原router/login的fullPath和safeLocalRedirect支持密码/飞书登录后回跳；报表再次按当前登录账号权限查询。
