## 结果与范围

同步任务以“当前计划摘要”替换原定时规则及独立下次执行列，展示频率、资源对应的采集口径、时区、错过策略与北京时间下次执行时间。摘要放在资源类型之后，便于首屏阅读。库存显示当前快照，商品全量不显示时间过滤，退款与财务流水使用对应的业务时间口径。

功能文件仅限 frontend/src/utils/syncPresentation.js、frontend/src/views/integrations/SyncJobList.vue、frontend/src/views/integrations/SyncExecutionRecords.vue，另新增 frontend/tests/sync-plan-summary.spec.js。
