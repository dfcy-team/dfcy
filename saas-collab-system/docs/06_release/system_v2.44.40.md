## 本次增量

V2.44.39 的“按变体 ID 导入平台商品 ID”功能已成功导入 35,821 条；用户反馈的“报错信息”实为 14,742 条变体 ID 在当前租户明细中不存在，后端请求正常返回 200，无 500/504。

本版本只优化导入结果的可读性：

1. 移除技术 JSON 直接展示，改为中文汇总：处理行数、新增、更新、无变化、未匹配、跳过。
2. 未匹配数据明确提示“当前租户平台商品明细中不存在，已跳过”，不再表达为整批失败。
3. 后端最多返回 100 个未匹配变体 ID 样例和剩余数量，避免大文件响应过大。
4. 保持租户隔离、平台商品 ID 可重复、只更新已有明细的原规则；未匹配变体不自动创建明细。
