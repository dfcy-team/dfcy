# V2.44.75 仓库 API 平台操作演练补丁

## 版本关系

- 版本：V2.44.75
- 父版本：V2.44.74
- 范围：修复正式数据形态下 WMS 配置被误判为店铺平台的问题
- 数据库迁移：无

## 问题与修复

- 正式接口在 `platform_config.api_type` 中返回 `inventory`，原页面只读取顶层 `api_type`，导致极风 WMS 错误进入店铺 OAuth 流程。
- 页面在选择授权接口前先加载并合并配置详情，统一兼容顶层和 `platform_config` 中的 API 类型。
- 极风 WMS 恢复显示“仓库接入”、“选择仓库接入”及仓库 API 操作，不再调用店铺授权、刷新令牌或撤销授权接口。
- Mock 数据改为与正式序列化器相同的嵌套数据形态，防止测试再次掩盖差异。

## 基线保护

- 未新增、删除或重排菜单与路由。
- 未修改权限目录、角色权限或导航样式。
- 未修改后端逻辑、数据库结构或生产配置。
