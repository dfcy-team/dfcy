## 变更范围

1. 内部系统只读数据接口：调用方来源 IP/CIDR 保存前校验并显示具体字段错误；支持规范的单机 `/32`、子网 `/24`、内网 `/16` 等网段；新建调用方类型不再提供“知识库”，存量记录仍可读取并编辑转换。
2. 基础档案：组合商品字典加载完成即启用导入确认；商品新增导入只处理本次实际创建的记录 ID；旧档案导入后补齐系统内部 SKU 编码。
3. 飞书接口：邮箱/手机号精确查询无结果时，按应用可见通讯录和规范化姓名生成候选，部门一致者优先；候选弹窗展示 Open ID、匹配依据及权限/范围错误。姓名候选仍须人工确认，不自动绑定；遍历有部门、用户和候选数量上限。
