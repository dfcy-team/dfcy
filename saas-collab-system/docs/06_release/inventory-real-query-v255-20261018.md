# V2.44.255 库存完整查询修正候选

## 实际基线

V254 阿里云完整库存接口验收失败，应用镜像已回到 V253/`5f4652bf2c2f8e265b0d574be194926497cd2290`；正式账本仍 34 条。数据库保留已成功执行的 commerce.0008 和 `idx_inv_latest_cover`，迁移记录 352 条。V254 不是阿里云已成功发布版本，不得把数据库当成 351 条迁移的旧状态。

源码基线为 V254/`687651709aa21802f3839aa1f1e12b2b3935af73`，使模型和已保留的迁移一致。本候选不新增迁移、不回退索引、不写生产业务数据、不修改权限或超时配置，不重试失败发布控制器。现有 V254 备份必须保留。

## 原因与改动

真实完整仓库汇总的只读 EXPLAIN 显示：排名子查询仅使用 id、身份、时间、tenant/source_run 字段，但优化器仍选择 `uniq_inventory_snapshot`，未选择可覆盖这些字段的 `idx_inv_latest_cover`。窗口存在排序，外层还需主键读取、商品关联和分组。V254 的合成 latest-ID 单 SQL 耗时不能替代完整接口验收。

本候选只在基表 WHERE 由 tenant 等值整数与 source_run 整数 IN 列表组成的宽范围查询中，克隆 QuerySet 并替换克隆的基表渲染对象，增加固定 `FORCE INDEX (idx_inv_latest_cover)`。不进行 SQL 文本替换，不修改原 QuerySet 或外层基表，别名重命名沿用 Django 基表实现，参数原样保留。其他数据库不生成 MySQL hint。

该定向控制用于非 daily 的排名源及观察日查询。日期、仓库、SKU、地区、SPU、平台连接及自定义权限条件不使用该 hint；daily 保留时间索引选择。租户和权限过滤、跨 run 排名、快照时间/id排序、虚拟商品排除顺序、每日趋势、明细筛选及分页契约不变。

完整合成接口还暴露观察日查找阶段：原先最多执行 14 次快照时间倒序 LIMIT 1，单次可达约 11 秒。改为授权 source 的 UTC 日期 DISTINCT、降序 LIMIT 14，一次返回最近 14 个实际观察日，保留稀疏日期及原有过滤顺序，不改成最近 14 个自然日。

候选的真实只读 EXPLAIN 已确认排名 U0 使用 `idx_inv_latest_cover` 且 `using_index=true`。EXPLAIN 未执行聚合，5ms 的计划生成耗时不是接口耗时，也不证明 P95 达标。

## 验收门槛

本地 90 项 SQL 守卫/库存工作台/库存分析/仓库权限测试及 39 项 commerce 模型、事实契约、SKU 关联测试通过，Django check 和迁移漂移检查通过。MySQL 编译测试核对 hint 仅出现一次、仅影响排名基表，并验证移除 hint 后 SQL 与参数和原实现相同；同时验证查询克隆不会污染原源、UTC 午夜及观察日仅一次查询。

完整 MySQL 8.4.11、128MiB buffer pool、真实模型/索引结构下，66 万合成历史、3 万库存身份、600 run、10 仓：默认工作台 200/12,547ms，受限非空工作台 200/563ms 且无 hint，默认库存分析 200/16,656ms。合成参考聚合与趋势一致。测试库仅一项无关的 development managed=False 视图迁移作了 fake，其余迁移正常执行；专用容器已删除。

合成 analytics 的请求连接未保留 15 秒会话保护的核验记录。原始 worker gate 因此保持 false，不修改该证据。根代理据实际功能/参考值及耗时结果作独立裁决，生产观察单独通过 connection_created 对每个新连接设置只读及 15 秒保护，并核验请求前后状态，另设 30 秒跨语句总预算。

一次生产隔离进程只读候选 GET 已完整 200，11,495ms、16 条 SQL、响应 14,901B；3 个仓库、14 个观察日、50 条重点明细。仓库汇总 3,594ms、一次观察日查询 1,550ms、daily 2,078ms、focus 2,076ms。请求前后只读及会话 15 秒保护核验通过；未改生产源码、服务镜像或业务记录。前端现有库存入口 30 秒超时未调整，该样本保留约 18.5 秒余量。

这是一份当前授权账号的单次 DRF 进程内样本，不代表生产 P95、并发负载、浏览器/JWT登录验收或全部筛选组合。生产 analytics 未重复探测；发布后仍需运营页面和范围相称的接口复验。正式版本仍 V253，本候选尚未部署。

原始诊断及验收证据保存在工作区 `审计产物/V255库存真实查询修正_20261018/`。失败或未覆盖项必须明确标记，性能门槛未通过时不送生产发布。
