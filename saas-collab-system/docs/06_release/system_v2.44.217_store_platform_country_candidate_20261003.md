## 用户可见变化

店铺档案按“平台 → 国家 → 店铺”查找。左侧平台和国家分组逐层显示当前用户有权查看的店铺数，默认折叠平台；选中平台仅展开其国家分组，选中国家后右侧显示对应店铺。平台、国家按店铺数排序；右侧保留店铺名称、档案编码、平台店铺名、平台/国家、状态和原有操作入口，详细字段仍可在“查看”中读取。查询、状态筛选、重置和 20 条分页与导航范围联动，切换范围时回到第一页。窄屏将导航置于列表上方。

阿里云正式站仅执行只读聚合校准：2026-10-03 店铺档案共 59 家，分布在 4 个平台、8 个“平台→国家”分组；最大平台 27 家、最大国家分组 14 家，当前 59 家均启用。该量级采用服务端分页与小型分组导航，无需将全部店铺行装入浏览器。预览使用模拟店铺，不以模拟数据冒充正式站实数。

## 数据边界与兼容

`GET /api/internal/master-data/stores/` 增加正整数 `platform_id` 和精确 `country_code` 筛选；空国家用 `__unset__` 表示，历史国家代码先去空格并统一大写。响应中的 `store_facets` 在租户和 `filter_master_data` 角色数据范围收窄后汇总，且不因列表搜索、状态、分页或当前平台/国家选择而丢失其他有权查看的导航分组。列表仍由服务端分页；异常或超长平台 ID 返回 400。

不增加菜单、路由、权限代码、角色授予、数据范围或数据库迁移；既有创建、编辑、导入、平台关联、API 接入、状态变更和删除处理保留。变更文件限定为店铺档案页面、通用资源页、店铺模拟数据、主档集合接口及其定向测试。
