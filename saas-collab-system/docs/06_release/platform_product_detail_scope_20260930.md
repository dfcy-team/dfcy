# 平台商品明细数据范围兼容修复候选（2026-09-30）

## 范围契约

平台商品明细含租户、平台、站点和店铺引用。`all` 只覆盖当前租户；`custom` 支持 `platform_ids`、`site_ids`、`store_ids`，并继续只读兼容历史字符串字段 `platforms`。同一角色的维度取交集，不同授予该操作权限的角色取并集。空列表不授予数据，缺失或非法范围拒绝访问。`warehouse_ids`、`supplier_ids` 不能直接映射到平台商品明细，任何包含这些字段的历史页面范围都拒绝访问并提示整改；角色保存时拒绝新增该组合。

页面附带的商品映射状态遵守独立的映射权限和范围。若映射范围无法安全应用，页面仍显示其独立获授权的商品明细，但不显示映射内容；主动按映射状态筛选会拒绝并提示单独配置映射范围。

## 阿里云历史配置整改候选

2026-09-30 18:07（Asia/Shanghai）只读复查：目标账号可用页面权限来自共享业务角色，其范围只有三个仓库；页面 GET 仍返回 `403 DATA_SCOPE_INVALID`。该角色关联多个在用账号，不能从仓库范围推断其平台、站点或店铺可见范围。

管理员需先确定页面应显示的具体平台、站点或店铺，再从原仓库角色移除此页面的菜单与查看操作权限，保留原角色的仓库范围及其他权限；另建只授予本页面权限、范围为已确认平台/站点/店铺的角色，按实际需要分配给账号。若页面还需商品映射状态，应单独确认可用的映射授权范围。涉及共享角色的变更应核对其余成员的访问需求。此候选没有更改生产角色或数据库，也没有部署阿里云。
