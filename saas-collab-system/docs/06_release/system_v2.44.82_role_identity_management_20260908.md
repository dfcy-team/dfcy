## 候选增量

1. 角色列表将“角色名称”与“系统标识”分列显示，同时支持按名称或系统标识搜索。
2. 自定义角色可单独编辑展示名称；系统标识在界面中只读，后端对任何已有角色的 `code` 修改请求强制拒绝。
3. 重复复制角色时，候选系统标识按 `-copy`、`-copy-2`、`-copy-3` 递增；最终唯一性仍由后端按租户边界校验。
4. 复制后继续打开新自定义角色的权限配置，并保持来源角色当前权限、数据范围、启用状态及委派边界。

V2.44.81 已包含权限快速/高级分配、高风险权限确认、业务数据范围、组织树、主/辅部门、租户隔离、角色复制服务端闭环等已发布能力；本候选只携带上述尚未进入主线的收口增量，不倒灌来源工作区的旧版实现。
