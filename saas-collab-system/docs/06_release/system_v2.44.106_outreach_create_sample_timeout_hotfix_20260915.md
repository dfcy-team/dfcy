# V2.44.106 建联任务创建送样超时修复

日期：2026-09-15。发布基线：已合并 V2.44.103 功能与 V2.44.104 修复的主干提交，`7d7abfd840786e282dad1762d72f9c81ea3da6d2`。

## 问题

在建联任务详情抽屉点击“创建送样”时，前端会先请求建联任务选项，并携带 `include_influencers=true`。该参数会触发全租户达人候选及送样状态关联扫描；数据量较大时超过前端统一 10 秒请求时限，弹窗无法打开并提示加载失败。

## 修复

- 创建送样弹窗只加载店铺和 BD 基础选项，不再预加载全租户达人候选。
- 任务或建联目标中已有的达人仍由现有逻辑注入送样表单。
- 保留达人昵称解析、按昵称建立档案、黑名单及未完成送样状态校验流程。
- 增加回归约束，禁止创建送样入口重新启用全量达人选项扫描。

## 验收口径

- 点击建联任务详情中的“创建送样”时，请求使用 `include_influencers=false`，弹窗可正常打开。
- 已关联达人的送样表单能正确回填达人；未关联达人时仍可通过昵称解析或建立档案。
- 达人模块针对性前端测试及生产构建通过。
