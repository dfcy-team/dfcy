# 出入库明细发布候选

入口为「库存管理 → 出入库明细」。提供入库、出库和全部汇总，按仓库所在国家、仓库、当地业务日期及 SKU 或单号查询。单号进入来源单据的可见商品行，CSV 使用当前生效的查询条件。权限沿用供应链查看和库存数据范围。

## 发布与核对

1. 使用累计发布基线集成该分支的功能提交。仓库包裹同步及其迁移依赖已在 V490 候选基线 `ee8798f2`。
2. 先备份，应用 `sales_management.0012_warehouse_outbound_line`，再更新 API 与仓库查询 worker。
3. 对各业务租户执行 `python manage.py backfill_warehouse_outbound --tenant-id <ID>`，登记只读预演汇总。完成发布审批后传入 `--apply` 回填。重复运行替换原投影。同一租户同仓同单号如出现在多个订单的投影中，菜单查询和导出均排除该单。
4. 按国家核对预演结果、回填表与菜单。用同一期间和筛选条件核对分页总数及 CSV 件数，再用具备仓库范围限制的账号验证列表和导出。
