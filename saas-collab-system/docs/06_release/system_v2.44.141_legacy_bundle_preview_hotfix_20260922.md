# V2.44.141 旧组合关系预览入口与阻断分类

## 目标

- 将“旧组合关系迁移”直接加入商品明细页“导入与导出”菜单。

- `bundle_services.py`：返回 `match_reason`、`match_count`、`error_breakdown`；修正带 SPU 过滤时过早截断候选的问题。
