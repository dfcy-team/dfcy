# V2.44.253 供应链协同与供应商工作台优化

登记日期：2026-10-18（Asia/Shanghai）。以 V2.44.252 主干为基线，发布目标为原虚拟机功能发布通道；不发布阿里云。

## 业务变化

- 采购单按待处理、部分发货、运输中、待入库汇总，单据内连接下单、发货、集货、入库的实际进度。完整筛选范围统计，不以当前页代替总数。
- 按 SKU 核对剩余数量，单外加发及某 SKU 超发不会抵扣其他 SKU 未发或未入库数量。批次到仓与确认入库保持区分。
- 供应商采购与分批发货适配手机卡片，商品图片延迟加载并复用已加载资源；批量读取单据关联数据，避免逐单查询。
- 国家名称来源基础档案；本地备齐 267 份旗帜资源，当前 27 个国家档案均可匹配。旗帜按需加载，不拉取全量图片。
- 供应链页面、供应商工作台和弹窗共用本地系统字体与字号层级；费用单号保持单行。
- 自动通知未接通时仍显示人工通知正文，含采购单号、供应商、国家、总数量、总金额、备注单号；支持复制、下载既有采购 Excel 与 SKU 标签 PDF，并提供正式本站的供应商登录链接。内部备注不外发。已有自动尝试时提示先核对原群。

## 边界与验收

无数据库迁移、新权限、新菜单、新服务端口或库存写入；不修改真实通知通道、凭据、外部群绑定，不自动发送真实消息。供应商链接仍要求原有登录与订单授权。既有自动投递状态保持其原义，人工复制和下载不登记为已送达。

本地预览与 VM 只读快照、性能探针位于代码库外的开发交付目录，不随本版发布；正式版本不包含只读样例服务或测试数据。

85 项定向后端测试、95 项前端测试、生产构建和源码扫描通过。单 SQL 履约统计在当前 VM 23 张样例订单中位约 16.53ms；仅代表该数据量的查询耗时，不代表端到端 SLA。首屏同国旗帜共用一条请求，无在线字体。

发布前需独立审查、精确候选 CI、受保护主干 CI 与既有发布门禁；部署后应核对运行 SHA、固定镜像、静态旗帜可访问、页面/授权只读接口和服务健康。无迁移场景保留现有不可变镜像回退点。本登记不代表已部署或真实外部群投递已验收。
