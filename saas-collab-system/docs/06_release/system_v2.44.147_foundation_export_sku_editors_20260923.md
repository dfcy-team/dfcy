## 变更范围

1. 分类、属性、颜色、规格设置页面增加导出入口，按当前菜单的数据结构生成文件。
2. 商品明细中普通 SKU 和组合 SKU 进入不同编辑页。组合页按基本信息、组合信息、价格、重量、店铺 SKU 匹配、仓库与版本记录展示；普通页保留其专属信息。
3. 组合子 SKU 的数量与成本价分摊比可在新建、批量导入和编辑时维护；分摊比写入当前关系和首版及后续版本快照；无效比值被拒绝。
4. 普通 SKU 仓库库存展示在库、已锁和可用数量；旧 SKU 编码仍仅允许管理员修改。
5. 组合商品 BigSeller 导出按选中商品逐一读取完整 SKU 与成分关系，输出每个子 SKU 的编码、数量和成本价分摊比；成分缺失时报错，不生成不完整文件。
