# V2.44.84 飞书达人增量导入兼容层

## 发布边界

- 候选版本：`2.44.84`
- 严格父版本：已部署、已登记的 `2.44.83`
- 父版本提交：`338085edb3d163a09987291d4cc0a5adf89d933d`

- 本版本只发布应用兼容层和数据库结构，不携带飞书源文件，不在部署阶段执行数据导入。
- 正式数据写入必须在本版本部署、登记和只读预检通过后，继续经过独立导入门禁、导入前新备份、明确审计执行人和同批次幂等校验。

## 兼容能力

1. 增加 `direct` 直接送样类型；直接送样不得关联建联任务或目标。
2. 增加任务与送样的受控飞书快照适配器，保留源状态、源日期、源成本和审计事件，不使用导入执行时间伪造业务时间。
3. 状态事件以租户、来源和源事件号唯一，重复执行为 no-op；旧事件在对象已推进到更高状态后仍可安全重放，损坏或串用事件会拒绝。
4. 仅本次受控飞书来源允许任务负责人和送样负责人不同；普通 UI/API 来源继续保持负责人一致约束，其他租户关系、店铺、商品、达人及目标约束不变。
5. 当前来源和获批旧来源的记录可通过稳定业务号迁移；同一来源的身份冲突、重复候选、其他来源占用和跨租户记录均 fail-closed。
6. 全量来源清理只做来源限定的软删除，并要求数据库中已完成批次及其完整 reconciliation manifest 摘要完全匹配；空清单、临时对象、失败批次和摘要漂移均拒绝。

## 数据库迁移

- `0015_samplefulfillment_direct_link_type`：扩展送样类型 choices，不改写存量行。
- `0016_fulfillment_status_import_identity`：为送样状态事件增加 nullable 来源身份字段及条件可用的唯一约束；历史人工事件保持空值。
- `0017_importbatch_manifest_digest`：为导入批次增加 manifest SHA-256 字段；历史批次默认空值，因此不能被误用作本次来源清理凭证。

三项迁移均为向后兼容结构变更，无物理删除、无存量状态回填、无权限目录或路由变化。
