# 历史补采容量配置

代码范围：V277 原始增量以 97da33175d225c05177f484a4ddab84f73726f04 为基线，本地候选累积在 V276 `25ca339ab83e3e7028919c93c745c149665ee5af` 之上。本批仅改后端派发准入、设置和测试，无数据库迁移、菜单或前端修改。

新增环境变量 SYNC_DAILY_LANE_CAPACITY、SYNC_HISTORY_LANE_CAPACITY，默认均为2，表示执行加排队的在途名额，不是worker并发。有效范围1至16，非法值回退2，越界值截断。历史每轮派发上限跟随历史容量，同时受调用limit限制。

本版本为仅部署代码：不修改运行环境变量、容器/Compose 配置或 worker concurrency；默认容量仍为日常2/历史2。夜间4并发是后续独立授权后才可评估的部署配套，不属于本版本的执行内容：届时可评估控制调度进程设置 `SYNC_DAILY_LANE_CAPACITY=2`、`SYNC_HISTORY_LANE_CAPACITY=4`，历史 `sync-history` 消费者 `concurrency=4`、`prefetch_multiplier=1`，同时保留日常消费者原值。任何环境变量都须由实际部署配置显式传入，不能只写入未被 Compose 引用的 env 文件。

本批没有修改部署文件或启动/调整 worker；生产仍需架构员审阅、受控构建发布及任何后续运行配置变更的单独授权。若之后评估提高并发，先核对应用服务器内存与 worker 单进程占用。现有历史窗口和逐页门禁保持有效，不提供跨午夜窗口、自动降级或严格全局同店铺锁。

保留现有同主体准入检查、任务锁、序列围栏与消息证据；同一次准入快照内同店铺任务不可重复领取。不同通道及多调度器之间不增加新的分布式主体锁，因此应保留单控制调度器部署，不能据此声称任意多调度器全局互斥。

上线前观察单worker基线，再试2并发和4并发，比较每小时成功落库及完整日期覆盖、限流超时、数据库CPU/锁等待、应用内存。切片等待不是活跃耗时。不能用分段数量直接比较不同日期范围吞吐。

回退：先记录部署前实际运行配置；如后续获批的配置变更需要回退，逐项恢复该记录中的实际值，不假定历史 worker concurrency 或容量必为1/2。使用温和退出完成当前页/切片，不清理队列、游标或已落库数据。窗口结束不等于强杀在途请求。
