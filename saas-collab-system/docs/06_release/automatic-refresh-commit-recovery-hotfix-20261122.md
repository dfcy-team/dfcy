## 问题与行为

平台令牌刷新、托管保存已成功，但 SaaS 授权引用提交失败时，旧实现会撤销刚保存的新引用，后续只能进入不确定状态。此次对自动商城续期增加持久化恢复记录：提交失败保留新引用，由原调度器按既有三次尝试上限和退避策略恢复提交，不再次刷新平台令牌。

- 在平台请求前持久化操作标识与授权范围摘要；HTTP 请求在授权行事务外执行。
- 重试查询同一托管操作回执，校验租户、店铺、应用配置、授权代次、有效期及引用状态后，仅提交授权引用。
- 提交应答丢失时读回确认；托管查询短暂失败可继续有限次恢复；手动刷新不能与待恢复的自动提交并发。
- 原始令牌不进入恢复日志，展示掩码固定；只记录安全错误分类，不保存原始 SQL 或平台错误文本。
- 旧的无恢复日志、不确定或已撤销凭据保持隔离，不复活旧凭据，不借用同店铺广告应用凭据。

这不改变闪购清理、重建次数或写入范围；也不为人工刷新新增自动提交恢复流程。
