## 变更范围

1. 商品明细数据中，已生成 SKU 的“编辑”操作进入独立编辑页；未生成 SKU 的旧档案继续使用原编辑弹窗。
2. 单 SKU 编辑页提供基本信息、价格信息、商品属性、包装与重量、平台 SKU 映射、仓库与库存、修改记录七个工作区。
3. SKU 编码、所属 SPU、颜色和规格保持只读；支持商品名称、采购价、单位、图片、包装尺寸、产地、HS 编码、商品说明和销售状态维护。
4. 平台映射按内部 SKU 精确查询；仓库区展示每个仓库 SKU 的最新库存快照；商品图片支持点击放大。
5. SKU 普通字段修改写入操作日志，使修改记录能够覆盖字段编辑、状态变化和删除记录。
