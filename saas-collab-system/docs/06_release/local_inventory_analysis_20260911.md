## 修正范围

- 明细改为来源 SKU、内部 SKU、仓库名称/编码、库存数量、数量风险及快照时间。不再用指标聚合字段渲染库存快照。
- “数据可信度”改为“SKU 映射率”，展示已关联数/总数并说明未关联不代表库存数量错误；未关联内部 SKU 明确显示“未关联”。
- 仓库选项来自当前用户数据范围内的真实库存仓库；风险选项使用后端支持的缺货、低库存、锁定偏高、正常。
- 日期按 UTC，明细取日期范围内各仓库 SKU 的最新快照。风险条件在取最新快照后应用，避免旧快照重新进入结果。
- 趋势展示在手库存件数，每天每个仓库 SKU 只统计当天最后一次快照，避免重复同步累加。只有一天时显示历史不足，不计算覆盖天数或虚构趋势。
- 库存页面不把旧指标聚合或演示数据解释为真实快照。其他经营分析页保持原有适配。
- 筛选提交回到第一页；图表零值柱高为零。
