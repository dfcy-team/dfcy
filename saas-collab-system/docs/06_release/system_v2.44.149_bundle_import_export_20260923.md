## 变更范围

1. 组合商品 CSV 导入模板增加可选“图片URL”列。导入时校验 HTTP(S) 链接，使用现有图片缓存接口保存组合 SKU 主图；生成的 BigSeller 文件使用缓存后的图片地址。图片处理失败单列行号和原因，不把已创建的组合商品误计为整行失败。
2. 商品明细页顶部“导入与导出”菜单统一放置组合商品导入、旧组合关系迁移和 BigSeller 组合 SKU 导出。移除“新增商品”中的批量新增组合商品项，以及组合商品抽屉内重复的导入导出菜单。
3. 组合导出根据商品明细列表勾选的组合 SKU 逐一读取完整成分，输出子 SKU 编码、数量和成本价分摊比；成分缺失时阻止生成文件。
4. 组合商品导入模板补充可选旧 SPU 编码和旧 SKU 编码；拥有组合商品管理权限的用户可通过导入写入，旧编码随原子创建保存到对应组合 SPU/SKU。既有记录的旧编码后续编辑仍按管理员权限控制。
