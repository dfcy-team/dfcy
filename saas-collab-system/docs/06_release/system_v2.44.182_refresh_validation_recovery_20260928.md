## 范围

1. 新 Token 保存后，网络校验重试耗尽保留 `AUTO_REFRESH_VALIDATION_PENDING`，后续调度只验证新 Token，不再次兑换；保留原始网络错误，不由 StopIteration 掩盖。
2. 仅明确认证拒绝要求重新授权；其他失败提示核对权限、配置或绑定后重新验证。审计仅新增脱敏分类与 `reauthorization_required`。
3. 现有刷新入口对待验证/验证失败授权重新验证已保存 Token；成功恢复授权有效状态，但不自动启用停用任务。普通只读同步及手动同步预检禁止使用未验证 Token。
4. API 接入界面提供“重新验证新令牌”，区分已绑定待验证、验证失败与未绑定，不把校验失败误报为刷新成功。
