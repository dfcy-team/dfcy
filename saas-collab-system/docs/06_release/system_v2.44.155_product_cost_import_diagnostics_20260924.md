## 变更范围

1. 商品成本 CSV 导入兼容 UTF-8 与 GB18030，解决中文 Windows/Excel 导出的 CSV 在预检前因编码报错。
2. 文件解析失败也返回结构化异常、记录失败批次；页面展示行号、字段、原因，并可导出完整明细。存在异常时仍禁止确认导入。
3. 保持同一 SKU、同一仓库的成本期间版本规则：新一期可截止上一开放版本；补录早期成本必须填写不重叠的结束日期，不覆盖历史金额。
