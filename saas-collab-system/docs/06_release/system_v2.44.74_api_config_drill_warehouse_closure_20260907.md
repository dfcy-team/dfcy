- 版本：V2.44.74
- 父版本：V2.44.73
- 范围：阿里云 API 配置内容问题修正的后续增量

## 增量内容

- 平台操作演练根据接入配置的 API 类型区分商城店铺授权与库存/WMS 仓库接入。
- 库存配置只列出已启用、服务平台匹配且符合站点/区域条件的仓库档案。
- 仓库接入复用既有仓库 API 接入对话框，不调用店铺 OAuth、令牌刷新或店铺撤销接口。
- 库存同步任务精确记录 `warehouse_authorization_id`，只读能力矩阵跟随当前仓库授权与任务。
- 写入能力保持关闭，仓库整改入口指向仓库档案。
- 商城配置仍沿用店铺授权流程。
