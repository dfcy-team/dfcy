## 变更范围

1. 个人设置新增“使用偏好”，允许用户设置最大打开页签数。
2. 默认最大打开数为 15，可配置范围为 5–30；设置按登录账号保存在浏览器本地。
3. 达到上限后阻止打开新的页面页签，并提示用户先关闭不需要的页签，已打开页签仍可正常切换和关闭。
4. 超限阻止导航后，左侧菜单选中状态保持在实际当前页面，避免出现菜单与内容不一致。
5. 顶部页签改为独立的左对齐按钮栏，普通页签为浅灰样式，当前页签使用深色高亮。
6. 普通页签悬停提示“可以移动TAB页，可以关闭TAB页”；固定工作台页签明确提示不可关闭。
7. 保留页签拖动排序、手动关闭、会话恢复和移动端横向滚动能力。
8. 商品成本导入弹窗提供可下载的 UTF-8 BOM 中文 CSV 模板，不再向业务用户展示原始技术字段清单。
9. 模板以 `*` 标记 SKU 编码、生效开始、币种和确认成本四个必填列；后端同时接受带星号的中文列名和原有英文列名，CSV/XLSX 均沿用现有预检与确认流程。
10. 商品成本导入展示上传、解析校验和写入阶段进度；预检异常按租户写入 `DataImportLog`，页面显示异常批次号并可导出完整 UTF-8 BOM 异常 CSV。
