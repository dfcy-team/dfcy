# 员工委托只读查询候选审阅范围

日期：2026-10-01。基线：V2.44.201 / ce8a74be74936f7cfed47e3447e4a26e07fbe4f6。

目标是员工通过 NAS 知识问答查询时，只读取本人原生权限允许的记录与字段。既有机器 Basic 数据同步与共用登录身份合同不变。此文档不是生产发布或启用证明。

## 本批变更边界

新增独立员工委托授权、交换、撤销、能力目录与资源集合路由；数据库仅保存哈希授权码、哈希短时令牌及必要的绑定/撤销信息。原生业务 JWT 不作为委托令牌返回。数据路由只允许 GET，不接受 SQL、通用 URL、任意字段、任意员工 ID 或通用 ORM 条件。

全局功能和调用方显式允许范围均默认关闭。每次请求重新校验调用方审批/启用/有效期/CIDR、员工状态、租户、原生权限、DataScope、字段范围及授权版本。先限制记录再分页；分页不能携带越权总量。不实现财务总额、同比或趋势，不通过返回的局部行推算正式指标。

员工委托的 eligible 明确拒绝 Django superuser 与无明确租户的主体；fields_for 对 superuser 返回空，避免共享原生权限 helper 的超管短路绕过显式 FIELD/DataScope。authorize、exchange 和每次 principal 使用同一拒绝规则；普通主体升为 superuser 后，即使历史记录指纹相符，授权码和令牌也不能使用。该防护只在新委托边界，不修改共享权限服务、原系统超管、身份 SSO 或机器接口；本人原生 revoke-all 仍可撤销旧委托。

无菜单、角色权限编辑界面或既有调用方密钥改动。新增接口不能直接启用既有机器接口的全部 22 块。首批可用资源以代码中已经映射到原生权限和数据范围的显式合同为准，其他资源返回能力缺失。

## 默认关闭发布授权与启用门禁

用户已授权本批默认关闭的代码发布：登记版本、先部署虚拟机、再由阿里云通道审核发布并登记。发布必须接续最终 203 提交、解决迁移分叉、核验最终 SHA/CI/不可变镜像、分别备份并取得虚拟机回执；三项 EMPLOYEE_READONLY 配置保持 false/[]/{}，37 项 FIELD 定义不自动分配角色。当前尚未部署，文档不代表发布验收。

启用员工实时查询、修改生产功能开关、将知识库调用方加入委托允许范围或扩大角色字段权限不在该授权内，仍须另行审阅确认。启用清单必须包含具体 client/tenant/audience/回调、资源与字段、退出撤销集成、原系统岗位 A/B 页面对照和 NAS 双端联调结果。当前不修改生产权限、不启用数据查询。

## 回滚

紧急停用：关闭员工委托全局开关或移除对应调用方允许配置，立即停止新授权和查询；撤销已有委托凭据。保持机器同步和既有 SSO 不变。

代码回滚：按发布通道恢复核验过的上一不可变镜像与原运行时配置。新增委托表保留，不执行破坏性迁移回退；等候审计保留期与后续授权清理。NAS 必须同时关闭员工实时查询、清除对应加密短时凭据及员工隔离缓存，不能退化为机器服务账号全租户读取。

## 验收判定

独立 A/B 员工验证不同岗位的允许/拒绝、行列范围、跨租户和无凭据；有/无显式授予的 superuser 均拒绝委托，普通主体升为超管后历史 code/token 即使指纹相符也拒绝；停用与撤权后旧凭据拒绝；授权码过期/重放、错误调用方/受众、委托令牌访问写接口拒绝；能力目录不暴露未授权字段；游标不能跨员工、资源、过滤条件复用。只读查询时间不等于来源更新，结果必须携带业务更新时间。

仅自动化隔离测试通过不能宣称已与生产页面逐项验收一致。启用前仍需对选定资源与实际岗位执行原系统页面对照，记录待办与证据。
