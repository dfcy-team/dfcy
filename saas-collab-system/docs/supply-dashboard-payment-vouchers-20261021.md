# 供应链驾驶舱及付款凭证开发说明

## 入口与流程

- 新菜单：供应链协同 → 供应链驾驶舱（/supply-chain/dashboard）。单一页面切换全部可访问国家/单国家，国家名称与国旗复用基础档案。
- 业务页签：已确认采购、未发货、已提交发货未分配、未发运、运输中、到港、到仓待核对、运营需求剩余、入库差异行、预计到仓逾期与未维护日期。
- 费用页签按需加载，供应商/货运商分开：已知应结、当前累计登记、已知未结、超额登记、未定价/未确认数量、前10排行。
- 待办抽屉每次20条，可分页并跳转原发货、物流或费用页面。
- 原费用与结算 → 保存原金额登记 → 在对应历史行上传付款凭证；历史记录可补传。PDF/JPG/PNG，单个10MB，每条历史最多20份；点击文件名鉴权预览，另有下载。

## 统计与权限

采购行按已提交有效发货逐行扣减，发货按有效批次分配扣减；支持多次发货和分批集货，负剩余钳为0。批次阶段互斥，已确认入库不重复计到仓待核对。待拆采购扣除有效采购草稿及已确认采购预留。

沿用供应链现有租户/内部账号/采购单及批次范围。国家筛选不增加权限；混合未授权来源批次沿用原规则整体排除。当前金额仅取每个来源当前结算版本，不累加历史累计额；未知应结单据不计已知应结金额。未建立新汇率或币种换算口径。

凭证私有存储，列表不查询二进制，下载校验所属租户、授权来源和历史修订。上传有类型/大小/真实图片校验、幂等与审计；不变更原累计金额，不执行付款。

## 性能及验证

驾驶舱使用数据库分组/子查询，不按订单逐条请求；国家切换和费用页签按需请求，过期响应被丢弃。明细分页，前10排行，图片使用本地国旗。附件只在预览/下载时加载。查询次数回归确认增加订单不会增加逐单SQL。

## 明确边界

本次驾驶舱为已有供应链单据的一期实现。WMS可用库存已通过独立inventory页签按需读取，独立检查sales_management.view权限。按租户/站点/仓库/源SKU选最新身份，再检查来源状态和failed_count、available_qty字段、24小时新鲜度、映射及国家一致性；排除虚拟和组合商品。任何问题均不回退旧记录、不伪造0；同国多仓库数量相加。它代表可用数量，不是on_hand总量；库存货值仍待统一成本口径，不能把本系统入库流水当成WMS库存。未开发生产进度推断、周转/滞销预测、银行核验及自动付款。PDF内嵌iframe被Edge拦截后已改为鉴权读取Blob并由用户点击新窗口查看，隔离PDF实测可见内容；未降低浏览器安全设置。部署环境的真实数据性能仍需发布后验收。
