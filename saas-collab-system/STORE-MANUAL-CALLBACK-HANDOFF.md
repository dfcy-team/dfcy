## 入口与使用

店铺档案 → API 接入 → 选择接入配置并发起平台授权 → 在平台确认后复制浏览器完整回调 URL → 粘贴“手动回填回调地址” → 提交回调并完成授权。

这是自动回调失败时的补充入口，不是修改平台登记的回调域名。正常自动授权保持不变。已自动完成的回调不能重放，可刷新店铺授权状态；过期或失败后需要重新发起授权。

## 安全与兼容

- 使用现有后台组件和权限提示；仅店铺授权显示，仓库流程不变。
- 完整地址经本系统固定 POST 接口提交，不访问用户粘贴的 URL，也不将授权码放到本系统请求路径中。
- 后端校验租户、发起用户、店铺、接入配置、授权数据范围及原回调域名/路径。
- 复用原 OAuth 流程的一次性 state、过期校验、平台参数校验和服务商店铺身份校验。
- 输入采用密码框，不存入本地存储；提交结束、重新加载和关闭弹窗时清空。不回显服务商错误中的敏感内容。
- 新增端点：POST `/api/internal/integrations/store-authorizations/oauth/manual-callback/`。
