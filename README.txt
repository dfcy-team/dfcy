鼎峰 ERP 目录
==============

erp/
├── common/                 共用工具（路径、Excel、MySQL、配置加载）
├── config/                 批量导入 ini 配置
├── platforms/
│   ├── tiktok/             TikTok 全部代码（见 platforms/tiktok/README.txt）
│   └── shopee/             Shopee（开发者 B 独立开发）
└── web-portal/             统一网站（登录、授权、导出）
