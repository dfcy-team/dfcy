## 三、根因分析

### 3.1 不是时区问题

若为时区或日期边界问题，通常会出现：

- 有消耗行数不一致  
- 总花费、订单数偏差明显  
- 某日数据整体偏移  

实测 **112 行有消耗、43 单、总花费几乎相同**，说明 **2026-06-16 当天的有效投放数据已对齐**。  
官方文件名 `00 ~ 23` 表示账户时区自然日，我方 API 请求为 `start_date=end_date=2026-06-16`，与官方为同一天。

### 3.2 行数差异：展开维度不同（主要原因）

| 维度 | 官方 Ads Manager | 我方当前实现 |
|------|------------------|--------------|
| 行粒度 | **广告计划 × 商品 ID × 视频创意** | **广告计划 × 主商品 × 视频创意** |
| 商品范围 | 计划可关联的**多个商品**（含跨商品归因） | 当天报表 item 级仅出现的**主商品**（通常每计划 1 个） |
| 零消耗行 | 保留（同一视频挂在多商品下） | 未展开，故少约 170 行 |

**示例（计划 HY107，`campaign_id=1864856082509265`）：**

| 项目 | 官方 | 我方 |
|------|------|------|
| 该行数 | 468 | ~416 |
| 涉及商品 ID 数 | **29** | **1** |
| 同一视频挂多商品 | 有（最多 8 个商品） | 无 |

官方多出的行 **几乎全部零消耗**，不改变花费与订单合计。

### 3.3 视频标题（补充说明）

| 项目 | 官方 | 我方（当前） |
|------|------|--------------|
| 有标题行数（约） | ~1534 / 1584 | ~404 / 1414 |

原因：

1. 已修复：`gmv_max/video/get` 需读 `item_list`、`need_auth_code_video=True` 等（此前为 0 条标题）  
2. 仍受限：开放 API 视频库约 **495** 条，报表视频约 **1388** 个，无法覆盖全部历史投放视频标题  
3. 可选增强：申请 **TikTok 账号** 权限，使用 `identity/video/info` 按 `item_id` 补标题  

**标题与行数差异为两个独立问题。**

   - 总行数约 **1418**（仍少约 166 行）

   - 需更完整商品池（店铺商品目录 + 报表商品并集）才有机会逼近 **1584** 行

## 五、对齐方案（建议分阶段）

### 阶段 A：保持现状（P0 已满足）

- **适用：** 只关心花费、订单、ROI、有消耗创意  
- **动作：** 无  
- **结果：** 金额与订单与官方一致；行数少约 170 行零消耗行  

### 阶段 B：行数对齐官方（推荐，若需与官方 Excel 行数一致）

**思路：** 按「计划 × 商品池 × 视频」展开拉取。

```
1. 商品池 = 并集：
   - 当日各计划 item 级报表中的 item_group_id
   - 店铺商品 API（products/search）返回的全部 item_group_id / product_id
   - （可选）campaign/gmv_max/info 中的 item_group_ids

2. 对每个 (campaign_id, item_group_id)：
   - 调用 gmv_max/report/get（创意维度 + 全量指标）
   - 分页合并

3. 去重键：(campaign_id, item_group_id, item_id)
   - 有报表数据的行：用 API 指标
   - 无数据的组合：不生成（或仅当官方逻辑需要时补零行——待确认）

4. 关联 gmv_max/video/get 补视频标题、账号、授权类型
```

**预期：**

- 行数：由 1414 → **接近或达到 1584**（取决于商品池是否覆盖官方 97 个商品）  
- 有消耗行、总花费、订单：**保持与现网一致**  
- 导出耗时：由约 **1～2 分钟** 增至约 **3～8 分钟**（计划数 × 商品数 × 分页）  

**风险：**

- 商品池若不全，仍可能少几十行  
- API 频率需控制，避免限流  

### 阶段 C：视频标题增强（可选）

| 方案 | 说明 | 依赖 |
|------|------|------|
| C1 维持 API 视频库 | 覆盖约 30% 标题 | 现场商务商店（已有） |
| C2 申请 TikTok 账号权限 | `identity/video/info` 按 item_id 补标题 | 新权限 + 重新授权 |
| C3 本地标题缓存 | 首次用官方 Excel 导入，后续复用 | 无新权限，需维护 |
