隐私政策 / Privacy Policy

最后更新 / Last updated: 2026-06-05

本隐私政策说明 {{ brand }}（域名：{{ domain }}，以下简称「本应用」） 如何收集、使用、存储和保护通过 TikTok Shop Open API 获取的数据。

This Privacy Policy explains how {{ brand }} at {{ domain }} collects, uses, stores, and protects data obtained through the TikTok Shop Open API.

1. 我们收集的数据 / Data We Collect

在卖家完成 OAuth 授权后，本应用可能通过 TikTok Shop API 读取以下类型的数据：

  • 店铺基本信息（店铺名称、区域、授权状态等）
  • 经营分析数据（产品、SKU、视频表现等）
  • 订单数据（订单号、状态、金额等）
  • 财务与流水数据（结算单、付款、提现记录等）
  • API 访问令牌（access_token / refresh_token）及授权元数据

After OAuth authorization, we may access shop profile, analytics, orders, finance records, and API tokens required to call TikTok Shop Open API on the seller's behalf.

2. 数据用途 / How We Use Data

  • 生成内部运营分析报表（Excel）
  • 维护店铺授权状态与定时数据同步
  • 排查 API 调用错误与服务可用性
  • We use data solely for internal reporting, authorization maintenance, and troubleshooting.

3. 数据存储 / Data Storage

数据保存在授权方自有服务器本地目录及受控配置文件中，不向无关第三方出售、出租或提供。 访问令牌存储于服务器本地配置文件，仅供本系统调用 TikTok API。

Data is stored on the operator's own servers. We do not sell or share shop data with unrelated third parties. API tokens are stored locally and used only for authorized API calls.

4. 数据共享 / Data Sharing

本应用不与广告商或数据经纪人共享卖家店铺数据。仅在以下情况可能披露：

  • 法律法规要求
  • 保护本应用或授权卖家的合法权益
  • 经卖家明确同意的情形

We do not share seller data with advertisers or data brokers.

5. 数据安全 / Data Security

  • API 请求按 TikTok Shop 规范进行签名与 HTTPS 传输
  • 服务器访问权限受控，配置文件不对外公开
  • 建议定期轮换应用密钥并限制运维人员访问范围

6. 数据保留 / Data Retention

报表与日志按内部运营需要保留。卖家撤销授权后，本应用将停止使用相关 token； 历史导出文件由运营方按内部制度管理，可按卖家要求协助删除（在法律允许范围内）。

7. 卖家权利 / Seller Rights

  • 在 TikTok Shop 卖家中心撤销对本应用的授权
  • 停止使用本应用的数据导出功能
  • 联系运营方咨询数据处理相关问题
  • Sellers may revoke authorization in TikTok Shop Seller Center at any time.

8. 第三方服务 / Third-Party Services

本应用依赖 TikTok Shop Open API 及 TikTok 授权服务。卖家使用本应用亦受 TikTok Shop 平台条款与隐私政策约束。

9. 政策更新 / Policy Updates

我们可能更新本隐私政策，更新后的版本将发布于 https://{{ domain }}/privacy。
