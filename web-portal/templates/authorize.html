授权步骤

  1. 选择或填写店铺（如 TKKJ1TH 泰国、TKKJ4PH 菲律宾）。
  2. 请先 登录网站，再点击「前往 TikTok 授权」。
  3. 授权链接请使用 https://；回调 URL 里的 code 只能用一次，失效后需重新授权。
  4. 若自动跳回并显示成功，即可使用 数据导出。
  5. 若跳转到 /callback?app_key=...&code=... 且提示「请从授权页选择店铺」，请复制地址栏 URL，在下方「粘贴回调 URL 授权」中选择店铺并提交。
