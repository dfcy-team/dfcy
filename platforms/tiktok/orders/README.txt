订单导出 — 单独运行说明
========================

配置: 本目录 **导入配置.ini**（或旧版 导出设置.ini）

运行
----
  双击 运行导出订单.bat

  或:
  python 订单查询.py --shop TK2PH --start 2026-05-30 --end 2026-05-30 --all

输出
----
  Z 盘: Z:\Tk每日数据\店铺分析API接口\订单数据表\<标签>_订单数据表_开始_结束.xlsx
  本地: 正式环境\订单\<店键>\（同上文件名副本）

店铺 token: ..\店铺配置\config_<店键>.env
